# Project-wide protocols

This directory contains project-wide registries, architecture contracts and immutable scientific direction decisions. Study-specific candidates, configurations, runbooks and frozen evidence belong under `studies/<study-id>/`.

Current subject-formation contracts:

- `epochs/subject_graph_vm_v1.json`: partitioned unified Subject Graph VM architecture and implementation stages;
- `epochs/entity_subject_functional_qualification_v2.json`: functional Epoch 1 entry contract;
- `decisions/subject_graph_vm_direction_v1.json`: accepted primary direction and D1-X/Y baseline status.
