# Long-run Analysis v4

Schema: `multi-seed-long-run-analysis-v4`.

v4 retains all v3 genetic, behavioural, group, affinity and cultural-transfer diagnostics. It adds `spatial_local_analysis` when evolution records contain `spatial-local-stress-diagnostics-v1` fields.

The panel distinguishes four questions:

1. Do high-pressure regions differ from low-pressure regions in the same window?
2. Does a given region become more cohesive when its own pressure changes?
3. Do pressure and cohesion change together after removing region means?
4. Does current local pressure predict cohesion in the same region at the next record window?

A global population curve is no longer required to define rise/decline. Local mortality, scarcity, hazard, crowding and population change are retained as separate axes; v4 does not combine them into a designer-weighted scalar reward or control signal.
