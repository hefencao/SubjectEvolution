# SubjectEvolution v0.155.0

SubjectEvolution 是一个实验性模拟项目，用于在不预设奖励和人类社会语义的前提下，研究类似主体的内部组织如何出现、变化并产生因果影响。

v0.155.0 不改变运行时或冻结科学结论。本版本把当前具有规范效力的仓库文档统一改为中文权威文本，并保留代码标识、CLI、协议字段、任务类型和数学符号的原始名称，以降低翻译造成的合同歧义。
