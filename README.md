# SubjectEvolution v0.136.0

SubjectEvolution is a deterministic CPU/GPU ecological evolution simulator with a partitioned unified Subject Graph VM research track.

Version 0.136.0 implements **Subject VM Stage 3C-22: selected historical-event coverage and reuse audit**. It reruns the frozen Stage 3C-21 constant-one and uncertainty-mean readout arms, reconstructs the complete delay-valid and above-threshold candidate opportunity set from read-only control checkpoints, and separates candidate eligibility from selected event identity coverage and reuse concentration.

The uncertainty readout changes ranking without changing the 112 unique eligible events or 432 above-threshold candidate references per source. It selects only 85–94 unique events, reuses some events up to three times, and does not select an event identity outside the constant-arm coverage. This is a diagnostic of fixed-bootstrap allocation, not a value, causal-credit, learning or universal-attention result. Permanent parameter retention remains disabled.

## Stage 3C-22 study

The authoritative executable steps live only in [`studies/d1z_subject_vm_stage3c22_historical_selection_v1/workflow.toml`](studies/d1z_subject_vm_stage3c22_historical_selection_v1/workflow.toml). The workflow runs the frozen Stage 3C-21 arms, re-establishes their isolation contract, produces the Stage 3C-22 read-only assessment and packages only declared evidence files without checkpoints.
