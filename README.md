# SubjectEvolution v0.163.0

SubjectEvolution 是一个实验性模拟项目，用于在不预设奖励和人类社会语义的前提下，研究类似主体的内部组织如何出现、变化并产生因果影响。

v0.163.0 完成思维链、统一 ThoughtEvent、通信与语言认知的文档治理。该版本不改变 runtime；它冻结下一轮实现边界，并把跨 seed/区域对象指称差异与“成本约束编码同态”登记为待验证假设，而不是预设语言结构。
