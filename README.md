# SubjectEvolution v0.139.0

SubjectEvolution is a deterministic CPU/GPU ecological evolution simulator with a partitioned unified Subject Graph VM research track.

Version 0.139.0 implements **Subject VM Stage 3C-25: deterministic winner-basin reuse audit**. It keeps the frozen Stage 3C-23 rank-two readout and reconstructs every eligible candidate from read-only control checkpoints, separating absolute and score-spread-normalized winner margins, historical-event eligibility opportunity, and repeated selection of one event across distinct query events and token vectors.

Across nine independent sources, small absolute margins remain common, but repeated winners have larger normalized margins than single-use winners in every source. They also receive more eligibility opportunities and are reused across distinct exact query vectors. The result identifies opportunity-conditioned deterministic candidate basins rather than proving causal credit, learning, value or universal attention. Permanent parameter retention remains disabled.
