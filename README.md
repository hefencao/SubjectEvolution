# SubjectEvolution v0.133.0

SubjectEvolution is a Python/CUDA-capable simulation research project for nested-subject existence evolution. The current engineering line remains Epoch 0 and does not authorize stable learning, subjecthood, scalar value or permanent parameter retention.

Version 0.133.0 implements **Subject VM Stage 3C-19: association-visible token geometry separability diagnostic**. It keeps the frozen nine-source, 32-entity, carrier-on `edge_forward_gate` top-1 baseline unchanged and performs external read-only analysis of the token coordinates actually visible to normalized-dot association.

The diagnostic finds that ports 29, 30 and 31 are the only association-visible coordinates; all 1,152 retained tokens equal `[0, 0, 1]`. Centered covariance rank is zero in every source, all 3,888 valid delayed query/candidate pairs are exact vector duplicates, every normalized-dot score is 1.0, and every best-versus-second score spread is zero. This establishes a current bootstrap geometry degeneracy, not a general impossibility result.
