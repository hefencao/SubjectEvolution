# SubjectEvolution v0.138.0

SubjectEvolution is a deterministic CPU/GPU ecological evolution simulator with a partitioned unified Subject Graph VM research track.

Version 0.138.0 implements **Subject VM Stage 3C-24: rank-two selection coverage and score-margin audit**. It reruns the frozen Stage 3C-23 rank-one and rank-two arms and reconstructs complete candidate opportunity, exact winner ties, best-versus-second score margins, selected historical-event identity coverage and reuse concentration from read-only control checkpoints.

Across nine independent sources, both arms retain the same 112 eligible historical events and 432 above-threshold references per source. Rank two eliminates exact best-score ties, but selects only a strict subset of rank-one identities in every source, lowers effective identity coverage and increases reuse concentration. This is an addressing diagnostic, not a causal-credit, learning, value or universal-attention result. Permanent parameter retention remains disabled.
