# SubjectEvolution v0.134.0

SubjectEvolution is a deterministic CPU/GPU ecological evolution simulator with a partitioned unified Subject Graph VM research track.

Version 0.134.0 implements **Subject VM Stage 3C-20: association-visible graph-state readout reachability audit**. It compares the frozen nine-source carrier-on `edge_forward_gate` baseline with one explicit fixed-bootstrap change: the existing action-producing node-0 state is additionally emitted to association-visible token port 29. Similarity, candidate limit, update scale, horizon, exposure, rollback and permanent-retention policy remain unchanged.

The new readout creates one-dimensional temporal token geometry and nontrivial normalized-dot score spread, but all bootstrap subjects still share the same value within each tick. It is therefore a replaceable temporal-phase shaping aid, not event identity, learned attention, value semantics or evidence of stable learning.
