# D0：正交四资源环境

## 研究问题

v0.30 三 seed atlas 的综合环境 signature 有效维度约为 1，说明存在空间斑块，但资源约束很可能仍主要沿单一“总体充足度”轴变化。D0 的目标不是增加更多同构资源，而是给既有四资源通道独立的空间、时间和周转结构，并把它们连接到不可完全替代的生命用途。

## 环境定义

`orthogonal-four-resource-niche-v1` 使用固定四通道最大布局。每个资源通道由以下配置共同定义：

1. 初始主空间波；
2. 初始次空间波；
3. 独立时间周期、相位和振幅；
4. 独立扩散率；
5. 公共 `resource_effect_matrix` 中的生命作用。

主线配置的主波方向为水平、垂直、正对角和负对角；次波使用不同频率组合。周期分别为 173、257、349、431 ticks，避免共享一个同步季节标量。

## 生态学含义

作用矩阵将四通道主要连接到不同身体用途：

- 通道 0：能量供给；
- 通道 1：完整性和结构材料；
- 通道 2：完整性与信息材料；
- 通道 3：结构材料与繁殖材料。

这只是模型内物理接口，不预先命名生态角色。任何“采集者”“储存者”“通讯者”等角色都必须由遗传性状和实际资源使用结果识别。

## 非反馈边界

环境生成和更新：

- 不读取实体位置或数量；
- 不读取谱系、群组、知识或策略；
- 不根据死亡调整资源中心；
- 不追踪或奖励稀有表型；
- 不自动维持生态型共存。

实体仍可通过采集消耗环境资源。这是世界内已有的物理反馈，不是多样性保护器。

## 有效维度

资源有效维度使用四通道场在空间样本上的协方差谱参与率。它同时受通道相关性和各通道方差平衡影响。高值表示多个资源方向具有实现方差，不代表它们已经产生不同适应策略。

600-tick、无实体采集的预注册审计：

- 空间有效维度均值：3.8670；
- 空间有效维度最低值：3.6497；
- 平均绝对空间通道相关：0.0209；
- 最大绝对空间通道相关：0.0595；
- 时间变化有效维度：3.2231。

## 下一证据门槛

D0 进入 D1 之前仍需三 seed 长跑确认：

1. 资源维度在实体采集后仍不坍缩为一个轴；
2. 不同资源亲和或未来容量性状呈条件性选择；
3. 多个表型在不同环境区域或阶段具有相对优势反转；
4. 种群没有因作用矩阵失衡而统一崩溃；
5. 结果不依赖单一地图分区尺度。
