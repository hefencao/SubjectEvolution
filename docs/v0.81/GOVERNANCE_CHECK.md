# v0.81 governance check

## Data versus expectation

D3-T replication is not a directory artifact or stale-plan false positive. It uses eight seeds disjoint from screen, passes every target-engagement check, retains direction in all seeds, and exceeds the unchanged practical threshold. The scientific task advances to confirmation.

## Task adjustment

The principal implementation task changes from candidate-specific migration repair to project-wide artifact provenance. Source runs and checkpoints are moved conceptually to `runs/`; frozen evidence and command chains are owned by `studies/`; analyses and mutable state are separated.

## Durable principles added

- Cross-version continuation is content-addressed rather than path- or label-addressed.
- A frozen result includes its entire available design and execution chain; legacy gaps are explicit and never filled by inference.
- Runtime migration must verify every expected hash before writing.
- Study-specific configs are colocated with the owning study.
- README files do not duplicate executable command chains.

These principles are now present in governance, architecture, tests, and command-line tooling rather than only in conversation.
