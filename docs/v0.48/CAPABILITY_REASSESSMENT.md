# Functional differentiation capability reassessment

## Why the previous route was incomplete

The v0.47 decision treated failed module-3 replication as a reason to move directly to resource-geography reversal. That was too narrow. A negative ablation result can arise because the tested architecture cannot express the hypothesized dependency, not because combinations or ecological differentiation are absent in principle.

The supplied D4-A run confirms this distinction. It contains repeated generic affinity × geography endpoint interactions, but no exposure-aligned outcome and only `0.003504` source-exposure range. The result does not justify a 300-tick confirmation and does not identify realized niche differentiation.

## What v1 could express

The archived `expression-gated-contextual-harvest-v1` architecture had four slots with the same structure:

```text
expression gate
+ ten fixed body/resource inputs
+ one bounded transform
+ one four-channel zero-sum harvest residual
```

All four routed outputs were summed independently. Consequently v1 could evolve:

- different thresholds and weights;
- different resource-request residuals;
- additive mixtures and cancellation;
- different expression strength.

It could not evolve:

- one module conditionally enabling or suppressing another;
- a weak upstream module being retained through a stronger downstream function;
- inherited module combinations whose effect exists only jointly;
- hierarchy among modules using the same output port;
- new embodied functions outside harvest requests.

Therefore v1 was sufficient for parameter differentiation, but not for the charter's broader combination-function differentiation.

## v2 capability added in v0.48

`expression-gated-compositional-harvest-v2` retains four fixed slots and the same sensors, resource channels and physical world. It adds six inherited active coupling genes forming a fixed acyclic hierarchy:

```text
module 0
  ├─→ module 1
  ├─→ module 2
  └─→ module 3
module 1
  ├─→ module 2
  └─→ module 3
module 2
  └─→ module 3
```

Earlier module signals multiplicatively modulate later contextual activation. Every slot still has a direct harvest output, so an upstream module may have a weak direct footprint while materially controlling a downstream module. Signed signals and weights permit contextual amplification or suppression.

The six coupling genes:

- are inherited and mutated;
- enter the real phenotype;
- incur explicit maintenance and development cost;
- are persisted in checkpoints;
- can be neutralized only at the coupling-output boundary while retaining their genes and costs.

## Remaining limit

v2 is intentionally bounded. It still routes only to the four harvest-request channels. It does not create new sensing, movement, conversion, storage, signalling or social-control ports. Thus v2 can test hierarchy and combination dependence among same-function modules, but it is not yet sufficient for the charter's full embodied-function differentiation.

The next experiment must determine whether this bounded compositional capacity is used by evolution. If it is used but functional dimensionality remains low, the next redesign should expand the versioned primitive/output vocabulary rather than alternate again between module ablation and environment reversal.
