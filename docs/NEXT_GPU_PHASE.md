# 下一阶段：GPU迁移顺序

v0.2 已在 CPU 参考内核中固定了提案→意图→结算→提交边界、稳定排序键、消息队列、候选主体图和阶段耗时。v0.3 已完成前 3 个 GPU 基础子阶段的独立对照实现。GPU实现应逐阶段复用这些语义，而不是重新定义行动或随机过程。

GPU版本不得一次性重写全部逻辑。建议按以下顺序迁移，并在每步与CPU参考输出比较：

1. 无状态随机键和基础分布；（v0.3 已完成）
2. 环境资源与信息场；（v0.3 已完成）
3. 规则网格、排序和伙伴采样；（v0.3 已完成）
4. 观察构建；（下一阶段）
5. 参数化策略批处理；
6. 移动与采集冲突；
7. 分享、关系事件和固定槽位；
8. 出生死亡与空闲槽位；
9. 群体标签传播；
10. 指标归约和异步日志。

每一阶段必须提供：

- CPU/GPU固定种子小场景；
- 随机分布统计对比；
- 离散事件一致或明确的统计容差；
- 性能剖析；
- 不允许策略读取新增的GPU内部真值。
