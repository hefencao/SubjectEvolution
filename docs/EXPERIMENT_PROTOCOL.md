# 实验协议与存在演化边界

## 基础实验

基础实验的目标是观察存在约束下的演化，而不是验证开发者写入的行为故事。除物理规则和明确列出的模型约束外，进入结果解释的数据必须具有可追踪来源：初代生成、观察更新、继承、突变、交互或选择。自主性、策略、主体偏移只能作为这些过程的结果或测量，不能作为直接赋值的能力标签。

默认 `run.experiment_mode="scientific"` 强制以下边界：

- 固定项限于行动的物理语义与可行性、传感特征词汇、遗传/突变机制、环境动力学和候选主体测量规则；
- 8 种行动对 16 类观察特征的 128 个偏好权重均为个体基因数据，不在策略代码中设置觅食、社交、繁殖或逃离偏好；
- 初代权重在有限边界内由稳定随机键生成，后代权重来自亲代继承与突变，生存和繁殖结果形成选择；
- 记忆只由观察和记忆动力学更新；候选主体及其偏移来自实体、谱系、关系结构和控制来源的测量；
- 采样后的行动替换和启发式方向覆盖会被拒绝。

每次运行在 `run_metadata.json.scientific_validity` 写入结构审计。`structural_evolution_provenance_valid=true` 只表示代码路径满足上述来源约束；它不是某项演化结论的统计证明。正式结论仍需多种子重复、预注册指标、对照、敏感性分析和不支持假设的结果保留。

繁殖容量冲突属于物理模型规则。当前配置必须显式使用 `entities.reproduction_capacity_arbitration="stateless-random-v1"`；归档配置缺少该字段时按 `stable-id-v1` 回放。两种规则的运行不得合并为同一实验组。`run_metadata.json.model_rules` 还固定记录同 tick 死亡是否释放槽位及容量拒绝成本，避免把三个独立问题混为一次“公平性”修改。

## 干预实验

干预用于观察系统响应，不能把期望结果直接写成行动。注册层预留以下稳定类别：

| 类别 | 含义 | 当前实例 |
|---|---|---|
| `introduce-existence` | 启发生成一个受约束、可持续或可复制的新存在，之后不直接控制它或其宿主 | 尚未实现；优先候选是可复制、可变异并经既有信息通道影响宿主的模因模板 |
| `modify-existence` | 修改或切断既有存在的状态、关系或输出能力 | 社会控制关闭、社会连接切断、记忆置乱 |
| `modify-environment` | 修改存在共同面对的外部条件 | 资源与危险场空间反转 |
| `modify-rules` | 修改演化或世界规则并观察后果 | 冻结基因突变 |
| `direct-action` | 采样后替换行动 | 只属娱乐协议，不是科学干预 |

道德、规范和模因可以作为存在进入模型，但至少需要：独立标识、跨承载体持续、复制或传播周期、可变异状态、维持/传播约束，以及只通过公开观察/控制边界影响承载体。仅给行动 logits 增加一个固定“道德奖励”或直接命令宿主，不满足此处的存在定义。

干预优先级当前低于基础演化正确性。实现新干预时仍须通过 `InterventionSpec` 声明类别、目标范围、是否直接控制行动及允许协议，避免未来扩展重新混淆科学实验与演示玩法。

## 娱乐协议

显式使用 `run.experiment_mode="entertainment"` 或 CLI `--experiment-mode entertainment` 后，可以启用社会方向覆盖和 `independent-foraging-override`（旧名 `restore-autonomy` 仅作兼容别名）。这些机制保留完整控制来源与队列指标，适合玩法、演示和管线压力测试；元数据会记录 `direct_action_control=true`，反事实摘要会发出警告，结果不得并入基础演化证据。
