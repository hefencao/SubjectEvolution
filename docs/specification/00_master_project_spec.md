# 嵌套主体存在演化模拟项目总规范

版本：v0.2  
性质：理论与工程总设计  
状态：基线规范

---

## 1. 项目定位

本项目构建一个大规模、可演化、可干预的主体存在模拟系统，用于研究：

1. 存在约束能否自发产生利益边界内聚；
2. 主体能否由物理承载体内部或跨承载体的因果结构涌现；
3. 个体、基因、社会、制度等不同尺度的主体是否会竞争、嵌套、整合和偏移；
4. 稳定多主体结构是否表现出高于个体简单叠加的适应能力；
5. 信息传播与接收误差如何改变主体边界、信任结构及演化方向；
6. 高层主体形成后，低层主体是否因依赖、功能退化或控制权转移而丧失独立存在能力；
7. 采样规则、观察截断和随机性如何影响演化结果。

本项目不预先认定圆球、基因或社会必然是主体。圆球是基础物理承载体；基因、身体连续性、社会关系、制度和群体均作为候选主体结构，由模拟轨迹与事后因果分析评估其主体性。

## 2. 核心理论命题

### 2.1 存在约束

设结构 \(X\) 在时刻 \(t\) 的存在状态为 \(P_X(t)\)。世界只规定客观过程：

- 资源产生与耗散；
- 结构损伤与修复；
- 信息传播与失真；
- 复制、继承与失传；
- 连接建立、维持与断裂；
- 死亡、解体和重组。

世界不直接告诉主体“什么有利于你”。

### 2.2 利益的操作性定义

利益不是预定义奖励，而是某一变化对结构未来延续概率的实际影响：

\[
I_X(a,H)=
P(P_X(t+H)>0\mid do(a))
-
P(P_X(t+H)>0\mid do(a_{\mathrm{baseline}}))
\]

主体内部可以形成预测、偏好或目标，但这些应由演化、学习或传播形成。

### 2.3 利益边界

主体边界不等于物理外壳。候选主体 \(X\) 对状态或实体 \(y\) 的维护归属可表示为：

\[
b_{Xy}(t)\in[0,1]
\]

边界可以跨越：

- 单个身体；
- 身体局部模块；
- 多个身体；
- 基因谱系；
- 社会连接；
- 公共资源与基础设施；
- 制度、文化和记忆。

### 2.4 可检验问题

模拟主要检验：

> 单纯的存在筛选，是否会产生能够识别、预测并主动维护某种利益边界的控制结构？

## 3. 关键术语

### 3.1 物理客体

具有位置、形态或物理状态的对象，如圆球、资源、地形单元、设施和信号场。

### 3.2 承载体

承载持续结构或控制过程的物理对象。一个圆球可以同时承载身体连续性、基因实例、社会身份和文化记忆。

### 3.3 控制过程

读取部分状态并影响未来世界状态的过程，可以是规则、基因表达、神经网络、制度、群体决策或学习算法。

### 3.4 候选主体

被模拟器独立记录和干预的持续因果结构。候选主体不代表已经被认定为完整主体。

### 3.5 主体性

连续量，至少包括：

- 跨时间持续；
- 边界可识别性；
- 因果控制；
- 内部协调；
- 损伤修复；
- 记忆或状态连续；
- 相对外部驱动的部分自主性。

### 3.6 主体偏移

控制中心、利益维护中心或延续中心从一个尺度迁移到另一个尺度。例如从身体转向社会，从宿主转向基因谱系，或从社会整体转向寄生性制度或信息结构。

## 4. 总体架构原则

### 4.1 双图分离

必须维护：

- **物理实体图**：位置、碰撞、资源、地形、身体组合和物理连接；
- **候选主体图**：承载、成员、控制、复制、社会、谱系、嵌套和重叠关系。

圆球ID不得直接等同主体ID。

### 4.2 五阶段分离

系统必须区分：

1. 客观世界状态；
2. 主体可获得的观察；
3. 主体形成的行动提案；
4. 实际执行结果；
5. 对不同候选主体延续结果的事后评价。

### 4.3 信息不透明

任何主体不得默认读取世界真值，只能通过传感器、接触、消息、关系连接、公共设施、信号场和记忆获得有限信息。

### 4.4 多时间尺度

物理、身体、社会、遗传、学习和演化过程使用不同更新频率。计算顺序不代表本体论优先级。

### 4.5 策略后端可替换

固定规则、状态机、小型共享网络、可塑性网络和强化学习策略必须实现同一观察—行动接口。

## 5. 世界与环境

### 5.1 基础空间

第一版使用二维连续空间和规则网格索引。后续可增加多层空间、建筑内部和抽象网络空间。

### 5.2 环境通道

静态地形：

- 高度；
- 摩擦；
- 通行成本；
- 障碍；
- 可见度；
- 承载能力；
- 基础资源生成率。

动态环境：

- 温度；
- 湿度；
- 风；
- 灾害；
- 污染；
- 疾病压力；
- 季节；
- 昼夜；
- 资源迁移。

信息场：

- 资源气味；
- 危险信号；
- 群体光环；
- 领地信号；
- 规范信号；
- 噪声、干扰和伪造信号。

### 5.3 有效环境多元性

丰富环境不是简单增加资源种类，而是增加不能由同一策略同时解决的独立约束轴。第一版建议包含：

- 能量与安全；
- 当前消耗与未来储备；
- 防御与移动；
- 个体独立与社会分工；
- 信息获取与暴露风险；
- 繁殖速度与后代质量。

## 6. 物理承载体

圆球至少具有：

- 位置、速度、半径、质量；
- 能量和结构完整度；
- 储存容量；
- 温度耐受；
- 固定模块槽位；
- 传感器和执行器端口。

模块包括：

- 外壳；
- 运动器；
- 储存器；
- 传感器；
- 信号器；
- 连接器；
- 攻击器；
- 修复器；
- 转化器；
- 繁殖器。

每个模块必须同时具有收益、能量消耗、维护成本、空间占用和潜在副作用。

## 7. 候选主体架构

候选主体通用字段：

```text
CandidateSubject
{
    subject_id
    subject_kind
    substrate_refs[]
    member_refs[]
    parent_subject_refs[]
    child_subject_refs[]

    persistent_state[]
    memory_state[]
    observation_ports[]
    influence_ports[]

    policy_id
    policy_version
    update_clock
    lineage_id

    persistence_metrics
    control_metrics
    boundary_metrics
}
```

初始候选主体类型：

- 身体连续性；
- 基因实例；
- 基因谱系；
- 社会关系；
- 稳定群体；
- 制度或公共设施。

被动结构只有状态转换；活跃控制节点有独立状态、更新时间、观察端口和控制提案。满足独立持续、传播、复制、跨承载体影响或独立因果解释需求时，可以晋升为候选主体节点。

## 8. 信息传播与误差

完整链路：

```text
客观状态
→ 信息源选择
→ 源编码误差
→ 传播媒介
→ 衰减、延迟、遮挡、混合和污染
→ 接收器采样
→ 接收属性偏差
→ 解码误差
→ 记忆整合误差
→ 主观观察
→ 策略采样
→ 行动意图
→ 执行误差
```

信息误差来源包括：

- 发送者感知错误；
- 编码能力不足；
- 有意欺骗；
- 距离衰减；
- 天气和地形；
- 多信号叠加；
- 接收器灵敏度；
- 注意力与先验偏见；
- 信任和身份；
- 记忆衰减与错误归因；
- 执行器损伤与控制冲突。

误差可能推动传感器、验证机制、声誉制度、欺骗策略、群体极化和主体边界变化的演化。

## 9. 统一采样

所有随机过程必须经过统一采样系统，使用无状态随机键：

```text
RandomKey
{
    run_seed
    tick
    simulation_phase
    subject_id
    stream_id
    draw_index
}
```

必须覆盖：

- 环境；
- 信号传播；
- 感知；
- 记忆；
- 邻居与注意力；
- 行动；
- 执行；
- 冲突；
- 繁殖；
- 变异；
- 疾病；
- 社会关系；
- 因果干预；
- Hero探索。

采样方法本身属于世界机制，必须进行消融和统计验证。

## 10. 多层控制与仲裁

基因、身体和社会是不同控制通道，不是预定义奖励函数。

示例提案：

- 身体：向资源移动；
- 社会：保护公共设施；
- 基因：提高繁殖倾向；
- 关系节点：向亲缘对象转移资源。

控制权可来自执行器所有权、遗传表达、身体限制、社会惩罚、资源控制、信任、契约、制度和信息垄断。实际行动必须记录各候选主体的控制贡献。

13. 出生、死亡、复制和传播；
14. 更新候选主体图；
15. 记录指标和抽样轨迹。

## 12. 社会与谱系主体

社会主体形成至少需要：

- 持续连接；
- 共同资源或风险；
- 成员边界；
- 内部信息传播；
- 冲突协调；
- 集体记忆；
- 对成员行动的因果控制；
- 合作剩余高于协调成本。

社会真实状态保存在共享结构中，个体只保存局部认知。

普通基因可先作为身体内部参数；跨宿主传播、拥有独立复制周期、影响宿主行为且与宿主存在潜在冲突的遗传结构，可以晋升为独立候选主体。

## 13. 主体性与主体偏移

主体性建议指标：

\[
S(X)=
w_pP_X+
w_cC_X+
w_bB_X+
w_iI_X+
w_rR_X-
w_eE_X
\]

其中：

- \(P_X\)：持续性；
- \(C_X\)：因果控制；
- \(B_X\)：边界可识别性；
- \(I_X\)：内部协调；
- \(R_X\)：修复能力；
- \(E_X\)：纯外部驱动程度。

主体偏移关注：

- 低层独立生存能力；
- 高层依赖度；
- 高层控制权；
- 自主模块退化；
- 延续中心变化；
- 环境反转后的恢复能力。

必须设计社会切断、群体记忆删除、公共资源删除、领导节点删除、环境反转、自主模块恢复、信号污染和关系随机化实验。

## 14. 学习与演化

三种变化尺度：

1. **跨世代演化**：改变基因、模块、网络、学习率、记忆和传感器；
2. **生命期可塑性**：记忆、信任、习惯、小规模权重变化和状态估计；
3. **Hero在线学习**：循环网络、世界模型、长期记忆、强化学习和模仿学习。

策略等级：

| 等级 | 实现 |
|---|---|
| L0 | 固定反应规则 |
| L1 | 参数化状态机 |
| L2 | 共享小网络 + 个体记忆 |
| L3 | 可塑性循环网络 |
| L4 | Hero在线学习 |
| LG | 群体共享控制器 |

研究初期大多数主体使用L1或L2。

## 15. 实验和科学规范

主要结论必须包含：

- 多随机种子；
- 对照组；
- 消融实验；
- 参数灵敏度；
- 环境反转；
- 主体结构干预；
- 信息噪声分级；
- 采样算法对比；
- 置信区间。

不得以一次有趣可视化作为证据。

## 16. 第一版MVP

建议：

- 100,000个圆球；
- 二维连续空间；
- 4种不可完全替代资源；
- 4至6条环境约束轴；
- 8种身体模块；
- 身体、基因谱系、社会三类候选节点；
- 每个圆球最多16条重要关系；
- 碰撞、连接、信号场三种交流；
- 统一无状态采样系统；
- 传播、接收、记忆、执行四类误差；
- 普通主体使用共享小网络；
- 参数主要通过跨世代演化；
- 不启用普通主体实时深度强化学习；
- 少量Hero保留复杂策略接口。

MVP回答：

1. 存在约束是否选择出边界维护控制？
2. 信息误差如何改变利益边界和社会结构？
3. 稳定社会是否形成可识别的高层控制过程？
4. 高度社会化是否造成低层主体独立能力退化？

\text{结构筛选}

\text{边界维护}
