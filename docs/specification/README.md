## 核心架构原则

- 圆球是物理承载体，不自动等同于主体。
- 物理实体图与候选主体图必须分离。
- 基因、身体、社会和制度都是候选主体结构，不预设完整主体性。
- 世界约束、主体观察、策略决策、执行结果和事后评价必须分离。
- 信息传播与接收误差属于演化机制，不是附属视觉噪声。
- 所有随机过程必须进入统一采样系统。
- 策略后端可替换，世界内核不得依赖规则、神经网络或强化学习实现。
- 主体性和利益边界由反事实干预及长期轨迹推断，不作为预定义奖励输入。

## 建议实施顺序

1. 完成CPU参考模型与统一采样API。
2. 建立GPU SoA数据结构和规则网格。
3. 实现信息传播、接收误差与行动意图。
4. 实现身体候选主体和基因谱系。
5. 加入社会关系与群体候选主体。
6. 完成主体偏移和反事实干预实验。
7. 最后接入Hero复杂网络及强化学习。
