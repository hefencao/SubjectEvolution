## 当前社会主体的含义

当前群体节点是候选主体而不是本体论结论。群体由高信任关系形成，其成员资源梯度被压缩成群体方向。群体方向通过独立控制通道影响成员，但影响强度仍取决于成员遗传社会倾向和动作采样。

## 已知简化

- 信息场的扩散形成空间延迟，但点对点消息延迟队列尚未实现；
- 群体识别采用固定轮数标签传播，是近似连通分量；
- 冲突处理尚未统一为通用Intent排序器；
- 社会依赖是能量来源比例代理指标，不是完整主体偏移判定；
- 普通主体网络没有在线反向传播；
- 资源模型仍是第一版抽象，并非完整化学或生态系统。

## 已验证基准

测试环境中的观测结果，仅用于规模参考：

- 5,000初始实体：约0.03–0.04秒/步；
- 100,000初始实体：冒烟测试约0.4–0.6秒/步；
- 5,000实体、200步运行中，高信任关系能够形成社会候选群体；
- 所有自动测试通过。

实际速度依赖CPU、Python和NumPy版本。
