# v0.4 实现状态

版本：0.4.0

## 实现边界

本版本以 CPU 参考实现为世界语义权威，并提供显式 GPU 混合执行路径；它不是完整设备驻留世界循环。字段、空间、观察和策略在 GPU 上运行，CPU 仍负责行动结算、关系、出生死亡和主体图，使每个主机/设备边界可审计。

## 当前社会主体的含义

当前群体节点是候选主体而不是本体论结论。群体由高信任关系形成，其成员资源梯度被压缩成群体方向。群体方向通过独立控制通道影响成员，但影响强度仍取决于成员遗传社会倾向和动作采样。

## 已知简化

- 群体识别采用固定轮数标签传播，是近似连通分量；
- 社会依赖是能量来源比例代理指标，不是完整主体偏移判定；
- 候选主体图为低频快照，尚不是任意嵌套的图数据库；
- GPU/CPU 仍有显式的动态状态和结果传输；关系、出生死亡、主体图和 CSV/检查点仍在 CPU，完整设备驻留循环尚未完成；
- 当前默认解析器仍是 CPU 严格参考实现；GPU/分布式解析器必须返回相同的 `ActionResolutionPlan` 合约，不得直接写世界；
- 延迟直接消息仍由 CPU 队列保存，但队列以数组批次而非逐消息 Python 对象表示，接收、噪声和容量裁决均批量向量化；
- 普通主体网络没有在线反向传播；
- 资源模型仍是第一版抽象，并非完整化学或生态系统。

## 已验证基准

本工作区的 v0.4 冒烟和 GPU 对照结果，仅用于正确性与规模参考：

- 5,000初始实体、500步：约0.03秒/步；
- 直接消息、意图结算和主体图均启用；
- WSL2、NVIDIA GeForce RTX 4070、CUDA Toolkit 13.3 与 `cupy-cuda13x==14.1.1`：完整测试套件 `35 passed`；
- 同一环境下，`verify_gpu_foundation.py --ticks 16` 通过，字段最大绝对误差为 `2.12e-6`（容差 `5e-6`）。
- 100,000初始实体、GPU混合路径、实际批量 `run()` 70步：首步 JIT 为 `0.342秒`；第20/40/60步窗口平均为 `0.088/0.096/0.097秒/步`，最后10步窗口为 `0.111秒/步`；结束时为131,056存活实体。该测量仅作当前机器规模参考，不是完整长运行吞吐承诺。

实际速度依赖CPU、Python和NumPy版本。
