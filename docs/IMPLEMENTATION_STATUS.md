# v0.3 实现状态

## 实现边界

本版本以 CPU 参考实现为世界语义权威，并提供可独立对照的 GPU 基础层；它不是完整 CUDA 世界循环。其任务是固定世界语义、随机键、观察结构、行动阶段和实验输出，使未来 GPU 实现可以逐项对照。

## 当前社会主体的含义

当前群体节点是候选主体而不是本体论结论。群体由高信任关系形成，其成员资源梯度被压缩成群体方向。群体方向通过独立控制通道影响成员，但影响强度仍取决于成员遗传社会倾向和动作采样。

## 已知简化

- 群体识别采用固定轮数标签传播，是近似连通分量；
- 社会依赖是能量来源比例代理指标，不是完整主体偏移判定；
- 候选主体图为低频快照，尚不是任意嵌套的图数据库；
- 设备版环境、信息场和空间索引尚未接入完整 GPU 世界循环；
- 普通主体网络没有在线反向传播；
- 资源模型仍是第一版抽象，并非完整化学或生态系统。

## 已验证基准

本工作区的 v0.3 冒烟和 GPU 对照结果，仅用于正确性与规模参考：

- 5,000初始实体、500步：约0.03秒/步；
- 直接消息、意图结算和主体图均启用；
- 100,000实体性能需要在目标GPU与其CPU对照环境重新测量；
- WSL2、NVIDIA GeForce RTX 4070、CUDA Toolkit 13.3 与 `cupy-cuda13x==14.1.1`：完整测试套件 `25 passed`；
- 同一环境下，`verify_gpu_foundation.py --ticks 16` 通过，字段最大绝对误差为 `2.12e-6`（容差 `5e-6`）。

实际速度依赖CPU、Python和NumPy版本。
