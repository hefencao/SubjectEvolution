# 知识分层与动态交换评估

## 结论

建议引入知识层，但不采用全局神经网络或大规模强化学习。知识应是可复制、可遗忘、可损坏且有成本的动态存在数据；基因保留较慢的身体参数、特征/行动架构和策略先验，知识保存从个体经历或其他承载体取得的局部策略残差。这样可以加快适应，同时不把期望行动直接写入控制器。

当前 128 个遗传策略权重暂时保留为 `inherited-linear-policy-v1`，不能在同一实验中静默改变其含义。知识接入需产生新的策略 schema，并与旧实验分开。

## 为什么不直接使用大规模强化学习

集中训练会引入模拟外部的优化器、全局回报和参数同步，难以证明策略数据来自世界内部存在。建议使用局部经验统计：承载体执行行动后，记录由物理结算产生的能量、完整性、物质、信息和繁殖机会变化；知识单元只更新所经历的“上下文—行动—后果”估计，不反向传播，不读取未来或全局适应度。

该后果向量不能预先压缩成固定的“善/恶”或单一奖励。承载体如何权衡后果，应由较慢的遗传参数或之后演化出的高层存在决定。

## 数据分层

建议的策略关系为：

```text
行动 logits = 遗传先验(观察) + 本地知识副本形成的稀疏残差(观察)
```

遗传层适合保存：

- 传感与行动结构、形态能力；
- 学习率、遗忘率、知识使用强度和交换倾向等慢变量；
- 无知识时仍可生存的低分辨率策略先验。

知识层适合保存：

- 某类上下文中行动后果的局部估计；
- 来源、置信度、样本量、创建时间和最后验证时间；
- 可交换的稀疏 action-feature 残差；
- 变体父 ID，使复制、损坏和模因分化可追踪。

知识不是控制器。它只能进入公开的策略观察快照，不能跳过提案—意图—结算—提交边界。

## 动态基础单元

不建议为 10 万个承载体预分配另一张完整 `entity × action × feature` 矩阵。首版可使用后端无关的动态 SoA arena：

```text
copy_id, holder_subject_id, content_id, parent_content_id,
context_key, action_id, outcome_vector, confidence,
sample_count, created_tick, last_verified_tick, encoded_bytes
```

内容目录保存不可变知识内容；每个承载体保存自己的副本 ID、局部置信度和验证状态。底层允许内容去重，但语义上副本可以独立遗忘、损坏或被替换。高频新增写入追加日志，按明确周期排序/压缩为 holder 分段；策略只读取当前 tick 发布的不可变 `KnowledgeObservationPlan`。这比 Python 对象链更适合未来 CPU/GPU 或分区实现。

容量应由字节预算或注意力预算约束，而不是无限字典。满容量时的保留/淘汰规则也必须是可审计约束，不能暗中保留“正确知识”。

## 交换及其代价

知识交换应生成显式 `KnowledgeTransferPlan`，至少记录发送者、接收者、副本/内容 ID、编码字节、提交 tick 和来源主体。实际提交需要支付：

- 发送能量成本：基础信号成本加每字节/每单元成本；
- 存储维持成本：每个活跃副本按 tick 占用能量或信息容量；
- 注意力机会成本：接收和验证知识占用有限槽位；
- 传播误差：复用信息通道的丢失、噪声和误分类，严重损坏产生新的内容变体；
- 验证成本：只有再次经历相应后果才能提高本地置信度。

交换不能被限制为“只在群体内部”，否则利益边界内聚会被规则强制出来。系统应允许跨边界交换并分别记录内部复制、跨边界扩散、发送成本和宿主净收益，让边界是否形成成为结果。

## 分阶段实现

1. `K1`：只实现知识目录、承载体副本、容量/维持成本和传输计划；知识尚不影响策略，用于验证复制、丢失和成本守恒。
2. `K2`：行动结算产生局部后果记录，知识副本按经验更新；不使用全局回报或反向传播。
3. `K3`：以新策略 schema 接入稀疏知识残差，并分别输出遗传、知识对 logits 和行动的贡献。
4. `K4`：知识内容具有复制谱系、变体和承载体分布，进入候选主体图；评估其持续性、宿主成本、复制优势和利益边界。

每阶段都需进行“无知识、私有知识、有代价交换、零成本交换”对照。零成本交换只作失效对照，不能作为正式世界规则。

## 必须报告的指标

- 遗传先验、私有经验知识和交换知识的行动贡献；
- 知识副本数、内容数、有效复制率、遗忘/损坏率和传播距离；
- 每个副本的存储、发送、接收与验证成本；
- 知识持有者相对非持有者的物理后果，但不预设单一奖励；
- 内部与跨利益边界的知识流、知识边界内聚；
- 基因策略坍缩与知识策略分化是否互相替代，而不是只报告总参数方差。
