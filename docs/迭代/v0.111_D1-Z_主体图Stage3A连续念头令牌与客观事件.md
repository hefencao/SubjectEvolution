# v0.111 D1-Z：主体图 Stage 3A 连续念头令牌与客观事件

## 1. 本轮结论

v0.111 实现分区统一主体图 Stage 3A，但最终设计不是“长期保存每 tick 实际执行的节点和边”。

实现过程中重新审查了归因历史的对象：若每个事件都持久化节点 ID、边 ID、执行 mask 和完整内部路径，长期存储会同时随实体数、事件容量和图规模增长；并且微小噪声会让两次近似内部状态成为两条不同路径，缺乏自然泛化。该设计还会让引擎持有主体内部的全知链路，而不是让主体图形成自己的紧凑内部表征。

因此本轮采用：

> 统一图自行输出固定宽度连续 token；长期 ring 只保存 token 与客观事件，不保存完整历史网络路径。

“念头”只作为工程上的非正式简称。当前没有证据证明 token 是意识、主观体验或成熟认知。

## 2. 为什么不是密码学 hash

严格 hash 会产生雪崩效应：内部状态只差一个很小数值，hash 也可能完全不同。这会破坏近似匹配和泛化。

本轮权威状态是连续、定长、可有界裁剪的向量。未来可以为检索或诊断建立指纹，但指纹不得：

- 替代连续 token；
- 定义学习上的相等；
- 参与 reward、credit 或行动；
- 成为 checkpoint 中唯一可恢复表征。

## 3. token 由谁生成

引擎不扫描全图后替实体计算一个固定摘要。节点结构新增两个通用字段：

```text
node_trace_port
node_trace_gate
```

任何表达节点都可以把当前标量状态投影到任意 token 坐标；多个节点可以汇聚到同一坐标。哪些节点参与、如何组合、是否输出 token，由图结构决定。区域名称不会自动获得 readout 权限。

没有任何 trace readout 的图仍可输出 action potential，但不会形成长期 token/event 记录。这允许大量内部计算保持未进入可延迟关联的状态。

## 4. 长期保存的内容

每个存活主体拥有固定容量 ring。记录包括：

- tick 与 event/intent ID；
- 当前 entity ID 与稳定 subject ID；
- 物理解析时可确定的目标 subject ID；
- 实际仲裁 action、成功/失败及失败原因；
- sampled probability；
- 连续 token；
- 八维 action potentials；
- energy、integrity、fertility、位置、速度、information store 与四维 raw store 的客观 delta；
- resolution resource/internal-resource delta 与 energy cost。

明确不保存：

- executed node IDs；
- transmitted edge IDs；
- output-node IDs；
- activation masks；
- 完整 node/edge state snapshot；
- trust、interest、knowledge value、polarity 或 reward。

ring 内存只取决于：

```text
entity_capacity × capacity_per_subject × token_width
```

以及固定事件字段，与图 node/edge capacity 无关。

## 5. 生命周期与兼容

- birth：继承图结构，但不继承历史 token/event；
- death：清除对应 ring；
- compaction：ring 与稳定 owner 一起移动；
- clone：复制已提交历史；
- checkpoint：精确 round trip；
- Stage 2 payload：只能显式重建空 token ring；
- disabled/Stage 1/Stage 2：trace 配置按 canonical 规则移除，不改变旧身份。

同 tick 尚未提交的 token 只作为瞬态存在，不进入 checkpoint。对 partial activation phase 执行 checkpoint 或 clone 会失败，而不是静默丢失状态。

## 6. 完全未实现

本轮没有实现：

- node/edge eligibility 增长或衰减；
- token 与后续事件的匹配；
- credit assignment；
- 主观正负值或 polarity；
- graph state、weight 或 topology 更新；
- physical trace cost；
- token readout mutation；
- GPU execution；
- Epoch 1 实验。

现有 `eligibility_value` 与 `eligibility_age` 仍必须保持零。

## 7. 下一步边界

下一步不能重新引入长期完整路径。需要单独冻结一种局部桥接机制，例如：

```text
短期局部 eligibility（节点/边本地衰减状态）
+ 历史连续 token
+ 后续客观事件
→ 仅影响未来图状态的通用三因子接口
```

但这仍只是候选架构，不代表已经授权。必须先解决：

- eligibility 是否位于 node、edge 或两者；
- 生命周期、衰减和容量；
- 如何避免所有客观后果被强制分配；
- 如何让不同图对同一事件产生不同内部变化；
- 计算、带宽、记忆和 plasticity 成本；
- 消融和稳定性门。

## 8. 科学证据边界

本轮工程验证最多证明：

- 图能够自行压缩内部状态为连续 token；
- token 与客观事件可以有界保存和恢复；
- 长期历史不随图 node/edge 容量增长；
- trace 记录不改变动作、实体轨迹或 RNG；
- 生命周期不会让历史泄漏给新主体。

不得描述为：

- 已经形成念头或意识；
- 已经完成归因；
- 已经学会价值；
- 已经出现主体雏形；
- 已经满足 Epoch 1。
