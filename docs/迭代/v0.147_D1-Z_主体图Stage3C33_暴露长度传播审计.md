# v0.147 D1-Z：主体图 Stage 3C-33 暴露长度传播审计

## 1. 主线位置

`Stage 3C-32 四臂 runtime 对齐干预冻结 → 3C-33 三条件 factor isolation → live-ledger 剂量完整性 → 评估支持审计 → 固定共同 horizon 完整轨迹对照 → 九 source 传播结论冻结`

本轮不增加新的 addressing、reward、learned weight、自动 keep/revert 或永久 retention。

## 2. 单一问题

Stage 3C-32 已建立 `subject-time alignment → selector identity → temporary update route` 的运行时因果链，但短时 paired window 只给出稀疏 Objective-Fact 结果。Stage 3C-33 检验把临时写入从 3 tick 延长到 6 tick，是否会在相同 11-tick horizon 下产生跨 source 可复现的下游事实传播。

## 3. 三条件隔离设计

- `3 exposure / 8 horizon`：冻结 Stage 3C-32 baseline；
- `3 / 11`：只延长 branch horizon；
- `6 / 11`：在相同 horizon 下只延长 temporary exposure。

每个条件保留 aligned/control、aligned/live、ablated/control、ablated/live 四臂，共 12 arm/source。九个 source checkpoint、候选、随机流、compute/storage、reservation、rollback 和 21 维逐坐标评估保持不变。

## 4. 剂量完整性

正式 live ledger 比较覆盖 18 个 source×alignment-mode。每组 16 个有效 transaction 的 identity、target、family、bounded delta、pre/post value 完全一致。baseline rollback duration 全部为 3，extended 全部为 6；target-tick exposure 从 48 精确翻倍到 96。

因此 exposure 操纵真实成立，不能把后续阴性或稀疏结果归因于“配置写了 6 tick 但运行时没有实现”。

## 5. 评估边界修正

最初的 rollback-complete paired-window 对照不能作为主要 exposure propagation 估计器：

- 每个 paired window 只观察后续 1 tick；
- `3/11` 完成 144/144 个 window；
- `6/11` 只完成 121 个 aligned 与 125 个 ablated window；
- 因此二者直接相减同时改变 exposure 和纳入评估的 window 集合。

本轮没有用该混杂结果冻结“剂量翻倍无效”，而是把 paired window 降为辅助诊断，并改用固定共同 horizon 的完整 final trace。

完整轨迹估计器在每个 source、alignment mode、branch role 中都使用完全相同的 144 个 event identity，覆盖 16 个稳定主体和 event tick 4–12。先逐事件计算 live-minus-control 的 21 维事实差，再在稳定主体内求和、跨主体平衡，最后做 ablated-minus-aligned 和 6-tick-minus-3-tick 对照。

## 6. 正式结果

3-tick common-horizon 条件中，完整轨迹 cross-mode effect 在 seeds `12301、12303、12308` 非零；6-tick 条件中在 `12301、12303、12305、12308` 非零。

exposure-only 轨迹对照只在两个 source 非零：

- seed 12305：fact-sum L1 = 0.1821444346，涉及 13 个坐标；
- seed 12308：fact-sum L1 = 0.0931600078，涉及 10 个坐标。

seed 12305 是 extended exposure 新增的非零 source；seed 12308 的轨迹幅度和坐标组成发生变化。其余 7/9 source 的 exposure-only 轨迹向量严格为零。

21 个 signed fact-sum 与 absolute-fact-sum 坐标都没有跨九 source 稳定正向或负向。因此结果不是“完全无影响”，也不是“可复现事实传播”，而是：

> 更长临时暴露在少数 source history 中能传播到下游事件轨迹，但效应稀疏、路径依赖，且没有稳定坐标方向。

## 7. 轻量治理检查

- **预期与数据不一致**：更长 exposure 没有形成预期的跨 source 稳定传播，但也不是完全零效应。根因审计发现旧 paired-window estimator 的 observation coverage 与 completion support 不适合该问题，已改用固定共同 horizon 完整轨迹。
- **新长期原则**：exposure propagation 必须分别验证 live-ledger dose、fixed common trajectory support 和 evaluation observation coverage；rollback-complete window 在支持集合变化时只能作为辅助诊断。
- **仅存在于聊天中的原则**：无。上述原则已写入 decision、epoch contract、study workflow、architecture 和 scientific issues。

## 8. 下一边界

Stage 3C-34 应复用当前冻结完整轨迹，做 read-only discrete action / objective-event threshold 与 crossing 审计。它应重点比较 exposure-responsive seeds `12305、12308` 与七个零对照 source，区分：

1. 内部路径差异是否跨越 action sampling 或 objective-event 离散边界；
2. 非零轨迹是否来自少数 crossing；
3. 零 source 是 subthreshold divergence、无 divergence，还是后续抵消。

不得直接新增 addressing、reward、learned weight、adaptive exposure 或 retention。
