# v0.30 后续实验方向

## 第一阶段：观察基线

运行新的三 seed、1500-tick 配置，先回答测量是否有足够动态范围：

- group refresh 是否产生可观测的 persistence、split、merge；
- 三种 atlas scale 的 signature distance 与 turnover 是否非零；
- lineage/social association 的 covered fraction 是否足够；
- association 是否因 singleton 或单一大群组机械饱和。

若动态范围不足，不增加主体机制，应先修正测量或环境异质性。

## 第二阶段：多元环境消融

保持实体和主体机制不变，预注册比较：

1. globally synchronized four-resource environment；
2. spatially asynchronous multi-niche environment；
3. 仅移除空间 phase；
4. 仅移除资源时间 phase 差异；
5. 资源 effect matrix 保持不变。

主要 outcome：

- environment signature dimensions/distance/turnover；
- subject succession Jaccard、split/merge；
- lineage/social exposure association 与 span；
- 有效谱系、群组数量和共同边界 benefit flow。

不根据单次结果事后选择 atlas scale。

## 第三阶段：主体结构敏感性

将以下规则作为独立 schema/预注册配置比较，而不是静默修改：

- group-label propagation rounds；
- trust threshold；
- minimum group size；
- adaptive refresh min/max period；
- directed minimum-label 与离线 weak-component diagnostic。

需要同时报告 succession 在不同测量协议下是否稳定。

## 第四阶段：结构—环境反事实

只有在前三阶段重复成立后，才加入低耦合 paired interventions：

- 同一 checkpoint 旋转/重排资源相位，但不改变实体状态；
- 冻结 group refresh 与保持共同边界；
- 删除候选社会控制贡献但保留关系；
- matched non-event windows。

目标是区分环境选择、结构维持和共同人口历史，而不是生成主体性分数。
