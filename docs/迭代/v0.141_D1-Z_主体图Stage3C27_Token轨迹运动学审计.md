# v0.141 D1-Z：主体图 Stage 3C-27 Token 轨迹运动学审计

## 目标

在不修改 runtime 的前提下，复用 Stage 3C-23 冻结 rank-two 面板，区分 age-one winner basin 中的三种来源：source-boundary 单候选强制选择、exact latest-on-tie 选择，以及由可见 token 局部轨迹产生的严格 normalized-dot 几何胜出。

## 实施

新增 `se-subject-vm-stage3c27-token-kinematics` 分析器、决策协议、声明式 workflow 和回归测试。分析器逐 query 重建完整候选集合，精确复核 stored winner ID 与 similarity，并比较 age-one candidate 与 best older candidate。对多候选 query 额外记录：

- normalized visible-token local step；
- angular distance；
- second difference 与相邻 step turn cosine；
- 第一个 readout 坐标是否保持；
- 当前 winner 是否匹配最近一次相同第一坐标状态。

本轮不修改 similarity、threshold、latest/top-1、candidate limit、target/carrier、delta、exposure、rollback、checkpoint schema 或永久参数保留。持久内存增长为 0。

## 九 source 真实结果

- 每 source 128 个 request：16 个无候选、16 个单候选强制 assignment、96 个多候选 assignment。
- 九 source 共 864 个多候选 query，其中 387 次选择 age 1。
- 386/387 次 age-one 选择由严格 score geometry 决定；仅 1 次需要 exact latest-on-tie。
- strict age-one query 的 source-balanced local-step 中位数约为 `3.78e-4`；older-winner query 约为 `7.57e-2`，中位比例约 201.5 倍。
- 第一个 readout 坐标相邻 tick 不变时，age one 在每个 source 中被选择的比例为 0.902–0.966。
- 第一个 readout 坐标发生变化时，older candidate 被选择的比例为 0.841–0.929。
- 在存在同第一坐标历史状态的 query 中，winner age 匹配最近一次同状态的比例为 0.867–0.951。
- 工程基线保持 pairing coverage 1.0、零 rollback failure、零 fact clipping、matched evaluation cost 和 0/21 stable objective coordinates。

## 结论边界

source-boundary 强制选择贡献总 age-one coverage，但多候选 age-one basin 几乎完全来自严格局部 score geometry，而不是 latest tie-break。第一 readout 坐标的状态保持/复现和第二坐标的缓慢变化共同形成采样轨迹；该结果不给速度、曲率、近因或任一坐标赋予价值，不验证 causal credit，不建立学习或主体性，也不授权 permanent retention。

下一边界是在全部运行合同不变时，只读检查第一坐标状态转移与第二坐标漂移是否形成跨主体共享的离散采样相位或 recurrent geometric basin，再决定是否需要任何年龄、机会或 addressing 归一化。
