# v0.101 D1-T：对抗、负重与侦察信息价值链

## 科学判断

D1-S 三个正式 seed 均完成 tick 1800，并全部产生物理异质、真实群内原料交换、多个持续加工分工群体；但 seed 100101 的最低人口为 47/128，低于预注册的 0.50 底座门，因此 D1-S 总体仍失败，不授权基因审计或社会角色结论。

此前没有出现类似斥候的持续分工，主要不是因为 tick 或 group 数量绝对不足，而是缺少完整的物理价值链：主体之间没有资源争夺，负重不影响移动，感知半径没有作用于危险，争夺信息不能进入信号，而且接收者即使选择 FLEE 也不会远离消息来源。

## 实现

D1-T 在禁用默认下增加角色中性的机制：

- 原料负重降低速度并增加移动能耗；
- 不同社会联盟在同格或相邻一格同步采集重叠原料时产生对称争夺压力；
- 争夺只造成双方相同规则下的能量与完整性损耗，并留下可衰减危险记忆；
- 已有遗传资源感知半径可同时用于危险梯度，不新增感知基因；
- 争夺压力进入已有危险信号；
- 来源明确的直接危险消息提供发送者方位，接收者选择 FLEE 时可远离该来源；
- 只读诊断记录低负重、远离群体中心、较大感知范围的信号发送者，以及同群接收者是否接收危险消息并沿远离来源方向逃离。

没有增加 ATTACK 职业、斥候标签、角色奖励、群体补贴或专属遗传坐标。

## 工程边界

- 新字段在禁用默认状态下从协议身份中剥离，旧冻结配置保持身份不变。
- 局部争夺结算在 CPU 权威提交阶段执行，因此 CPU/GPU 使用同一语义。
- 来源方位计算使用同一直接消息、稳定实体 ID 和周期世界距离，CPU/GPU policy 路径共享实现。
- 结果包默认包含 `reconnaissance_windows.jsonl` 与 `reconnaissance_summary.json`，checkpoint 仍需显式加入。
- D1-T workflow 只有冻结证据审计、配置生成、单 seed 机制 probe、摘要和打包；没有正式 panel、paired 或 gene 步骤。
