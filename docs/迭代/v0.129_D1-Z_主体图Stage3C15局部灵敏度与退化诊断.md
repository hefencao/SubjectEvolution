# v0.129 D1-Z：主体图 Stage 3C-15 局部灵敏度与退化诊断

## 1. 本轮问题

Stage 3C-14 已经证明 `node_bias` 与 `node_output_gate` 都可以进入 proposal、target binding、bounded update、temporary commit 和 rollback 链，但参数角色差异没有产生跨 source 稳定客观方向。继续逐个开放参数族之前，必须先回答：

> 六个通用参数族在当前 fixed bootstrap operating point 上，哪些机械上有局部影响，哪些因延迟状态、clamp 或代数退化而暂时为零，哪些虽然有影响却没有 eligibility carrier？

本轮选择路径 A：补充外部可观测性和实验可辨识性，不修改学习机制、eligibility、association、delta、horizon、exposure、实体规模、拓扑或永久保留政策。

## 3. 两个 operating context

仅检查 bootstrap 后第一次激活会错误地把 delay=1 edge 判为无作用，因为历史 node state 仍为零。本轮固定两个上下文：

```text
first-post-bootstrap
warmed-delayed-edge
```

第二个上下文先执行一次无干预激活，再从完全相同的 warmed state 创建 probe branch。它只是诊断所需的最小延迟上下文，不是延长正式 branch horizon。

## 5. 诊断结论

### 5.1 `node_bias` 与 `node_input_gate` 在当前 bootstrap 退化

node 0 读取 frozen `constant-one` input port 0。相同幅度的 bias delta 与 input-gate delta 在激活方程中进入同一个 accumulator。所有 probe response 的最大差异为 `5.960464477539063e-08`，符合 float32 运算顺序误差。

这只说明当前节点、输入和 operating point 不可辨识，不说明两个参数族在一般图上等价。

### 5.2 `node_trace_gate` 有机械影响，但不直接影响同 tick action channel

probe 稳定改变 target-weight thought token，但 one-step action potential 和 sampled probability 不变。它属于 token-channel sensitivity，而不是当前 horizon 下的直接 actuator sensitivity。

### 5.3 `edge_forward_gate` 是 delayed-context sensitive but eligibility unreachable

首个上下文中它为零是因为 previous node state 为零；预热后产生明确 action-potential 与 probability response。当前 fixed bootstrap 没有给 edge 0 设置 local eligibility gate/flag，所以该机械敏感作用点仍不能进入 Stage 3C-1 binding。

### 5.4 `edge_bandwidth` 的零响应来自 clamp 未激活

当前贡献始终位于 bandwidth 内部，改变 bandwidth 不改变 bounded contribution。该结果不能用于删除 bandwidth family，也不能证明其一般无作用。

## 7. 允许与不允许的解释

允许：

- 当前 fixed graph 存在参数族代数退化；
- delayed operator 需要最小有效上下文；
- sensitivity 与 eligibility reachability 是不同工程事实；
- `edge_forward_gate` 是当前最明确的“机械敏感但不可达”候选。

不允许：

- 把 derivative 大小解释为价值或优劣；
- 把离散 crossing 数解释为 reward；
- 把 zero derivative 解释为参数族无用；
- 自动开放 eligibility；
- 宣称 causal credit、learning、subjecthood 或 universal attention；
- 开启 permanent retention、automatic keep/revert 或 scalar objective。

## 8. 下一边界

若继续 fixed-bootstrap shaping，最小可验证方向是只给一个当前敏感但不可达的作用点增加 eligibility carrier。优先候选为 `edge_forward_gate`，因为它在 warmed context 已进入 action channel；`node_trace_gate` 只影响 token，可能需要更长因果链才能影响行为。

下一轮必须固定九 source、32 实体、8-tick horizon、exposure=3、bounded delta、nearest-token selector、topology size、rollback 和 Stage 3C-8 聚合，只改变一个 eligibility carrier。该建议尚未授权实施结果或永久保留。
