# v0.80 lightweight governance check

## Data versus expectation

The supplied D3-T data are internally consistent with a promotion-positive acute effect. Target exposure and neutralization are confirmed in every seed, every relative effect has the same sign, and the median effect exceeds the preregistered threshold. The unexpected element is direction: neutralization increases conversion, so the active support surface is suppressive on this estimand. That direction is retained rather than reinterpreted as a benefit.

## Task adjustment

The authorized task changes from screen execution to disjoint-seed replication. No new candidate is selected and no threshold or horizon is adjusted.

## Long-term principle

Inferential replication changes only the independent seed set. Changes in scale, horizon, cadence, source construction or mechanism configuration are separate robustness questions and require separate preregistration.

## Chat-only principles

The new replication/robustness distinction is now present in governance, architecture, status, configuration, protocol-audit output, validation code and tests. The existing concise validation-report and mandatory suggested-command rules remain documented.
