## 冻结结果

40 个 mode-event 的 REST output exposure DID 全部可从 node、delay-one recurrent edge 和 output contribution 精确重建。28 个 mode-event 具有非零 DID，所有已观测 active target 都属于 `edge-forward-gate`。

在该冻结支持上：

- inherited node-state component 最大绝对值为 0；
- state×gate interaction 最大绝对值为 0；
- input、bias 和 output-gate 结构 contribution 均为 0；
- 全部结构 DID 由当前 edge gate component 形成；
- float32 数值残差最大为 `1.7881393432617188e-7`。

crossing 的绝对 gate contribution 范围为 `0.0382690877…0.1220563799`，noncrossing 最大值为 `0.1677580923`。所以 temporary gate write 是当前 REST exposure effect 的直接执行来源，但其幅度不是 crossing classifier。

seed 12307 的 aligned/ablated crossing gate contribution 绝对差为 `6.705522537231445e-7`，符合 alignment-common 路径。seed 12401 的最高 opportunity gate contribution 为 `0.0823221356`，但 categorical pressure/余量比仍为 `0.6884819850`，没有 crossing。
