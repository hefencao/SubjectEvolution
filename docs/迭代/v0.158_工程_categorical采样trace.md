# v0.158：语义中立 categorical sampling trace

## 任务身份

```text
[ENGINEERING] policy: export neutral categorical sampling trace
```

## 目的

Stage 3C-39 将剩余不确定性收窄到未导出的完整 categorical competition 与 draw state。本轮只补观测能力，不执行 Stage 3C-40。

## 实现

- 普通采样与 trace 模式共用同一 categorical kernel；
- 导出完整 mask、masked logits、probability、CDF、uint64 RNG key、uniform draw、draw index、sampled action 与 CDF interval；
- paired runner 可按全部主体或指定 subject ID 导出；
- trace payload 从 checkpoint、restore 与 clone 的语义状态中排除；
- writer 不生成随机数，不参与 policy、intent 或 settlement。

## 完整性门

审计同时覆盖 fresh run 和同 source checkpoint 的 paired branches。trace 开/关必须保持 action、selected probability、config hash、checkpoint state hash、lineage 与 branch identity 一致；每条 trace 必须可重建 key、CDF 和 action。

## 科学边界

本轮不形成新的科学结果。只有完整性门通过后，Stage 3C-40 才可读取该 trace；仍不授权 value、keep/revert、learned weight 或 permanent retention。
