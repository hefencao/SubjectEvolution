# v0.102 D1-U：资源耗竭竞争与地形信号传播

## 1. 触发问题

v0.101 将不同联盟在相邻范围内的重叠采集解释为“对称损耗”。源码核对后确认，该损耗不是额外破坏资源，而是在资源已按采集量扣除之后，再从参与实体扣能量与完整性，并把压力写入 danger memory。这把自然的资源耗竭竞争重复叠加成了未明确建模的推挤或战斗伤害。

同时，资源 SIGNAL 使用动作前采样值；地形影响移动，却不影响场信号扩散或直接消息传播。上传的同 seed、同配置结果还显示 CPU 与 GPU-hybrid 对机制链是否存在给出相反诊断。

## 2. 科学判断

- 资源被一方采集后，其他主体面对的剩余资源下降，本身已经构成隐性竞争。
- 只有显式建模推挤、抢夺、破坏或攻击时，才应增加身体损伤。
- 竞争信号应映射到实际物理变量：资源剩余量和耗竭变化，而不是无条件映射到 danger。
- 地形既然是空间传播介质，就应影响场信号和点对点消息；但不得按消息语义、群体或角色选择性放大。
- 同配置机制在不同后端一边“存在”、一边“不存在”时，只能视为未资格化调试证据。

## 3. v0.101 移动公式（本轮不修改）

基础速度：

```text
v_base = 0.35 + 0.10 * clip(gene_5, -1, 1)
```

生理与地形乘数：

```text
Q = perfusion * contractile * sqrt(oxygen) * sqrt(tissue * structure)
locomotor_gain = 1 + max_speed_fraction * (2Q - 1)
terrain_multiplier = 1 - terrain_speed_penalty_fraction * T
physiology_terrain_multiplier = clip(locomotor_gain * terrain_multiplier, 0.1, 2.5)
```

负重比例及速度乘数：

```text
L = clip(sum(raw_store) / sum(effective_capacity), 0, 1)
load_multiplier = clip(1 - load_speed_penalty_fraction * L, 0.05, 1)
```

实际速度：

```text
v = v_base * physiology_terrain_multiplier * load_multiplier
```

移动能耗：

```text
base_power_cost = moved * movement_cost * physiology_terrain_multiplier^2
terrain_extra = moved * movement_cost * terrain_energy_cost_fraction * T
load_extra = moved * movement_cost * load_energy_fraction * L
```

D1-T 配置中负重速度惩罚和负重额外能耗系数均为 0.35；地形速度惩罚为 0.35，地形额外能耗系数为 0.25。

## 4. D1-U 修正

### 4.1 资源耗竭竞争

新增 `rival-harvest-depletion-pressure-v2`：

- 资源仍只由实际 harvest commit 扣除一次；
- 邻近不同联盟的同通道重叠需求仅记录 pressure；
- pressure 不扣能量、不扣完整性、不写 danger memory；
- 资源 SIGNAL 使用 harvest commit 后的当前资源场；
- 保留 pressure 仅用于观测局部竞争强度，不自动产生行为奖励或惩罚。

### 4.2 地形场信号扩散

令地形阻力 `T∈[0,1]`，格点渗透率：

```text
p_i = clip(1 - k_terrain * T_i, 0.05, 1)
c_ij = (p_i + p_j) / 2
S_i(t+1) = max((1-decay)S_i(t) + diffusion/4 * Σ_j c_ij(S_j-S_i) + source_i, 0)
```

地形只改变相邻格传输通量，不识别资源、危险或社会消息的含义。

### 4.3 直接消息衰减

沿发送者到接收者的最短周期网格路径计算平均地形 `T_path` 和格点距离 `d`：

```text
transport = max(1 - k_direct * T_path, 0.05) * exp(-distance_decay * d)
payload_received = payload_sent * transport
```

同一乘数同时作用于 payload 和 confidence。

## 7. 本轮实际调试结果

CPU seed 102011 完成 tick 600：终点 alive 55，运行中跌破预注册环境资格人口底线 64；记录 18 次竞争 actor-event、压力总量 13.7083、负重额外移动能耗 0.6497。竞争附加能耗和完整性损伤均精确为 0，证明语义修正已执行。
