# v0.112 D1-Z：主体图 Stage 3B-1 短期局部资格载体

## 本轮定位

本轮在 v0.111 连续内部 token 与客观事件 ring 之上，只实现统一主体图内部的短期局部 eligibility 载体。它为未来延迟关联提供可能的微观落点，但不执行事件匹配、信用分配或参数更新。

核心边界：

> 长期历史保存图自行产生的连续 token 和客观事实；微观节点/边只保留短期、局部、衰减的活动状态。两者在本轮不连接。

## 已实现

### 配置与存储

- 新增 `partitioned-subject-graph-vm-stage3b-local-eligibility-v1`。
- 新增 `local-decaying-activity-eligibility-v1` 配置：`decay`、`clip`、`max_age_ticks`。
- 节点和边具有图控制的 participation flag、gate、局部值和年龄。
- Stage 3A 及更早配置必须保持 eligibility disabled；disabled 配置继续从 canonical identity 中规范化移除。

### 本地活动标记

- 节点只根据实际执行后的有界输出留下局部值。
- 边只根据实际发生且受 bandwidth 限制的传输留下局部值。
- 标记的正负号只是计算方向，不是主观或客观价值。
- 未表达 participation flag/gate 的元素不留下资格。

### 衰减和生命周期

- 按实际经过 tick 做确定性乘法衰减。
- 达到固定年龄后清零并失效。
- birth 继承结构 flag/gate，但动态值和年龄清零。
- clone 和 checkpoint 精确复制已提交状态。
- death 清理；compaction 随稳定主体移动。
- v0.111 Stage 3A checkpoint 升级时只重建空 eligibility，不伪造历史活动。

### 中性

- 客观事件提交不写 eligibility。
- eligibility 不参与同 tick 或后续行动输出。
- 不消费随机数。
- 不更新节点权重、边权、gate、retention 或拓扑。
- 不扣实体物理能量。
- 长期 token/event ring 不保存 eligibility、节点 ID、边 ID 或执行路径。

## 明确未实现

- token 与事件匹配；
- 事件对 eligibility 的调制；
- credit assignment；
- reward、valence、polarity 或固定后果价值；
- 节点、边、retained state、gate 或拓扑 plasticity；
- eligibility 成本扣除；
- token readout 或 eligibility gate 的突变/发育；
- GPU Stage 3 执行；
- Epoch 1 panel、主体性评分或涌现结论。

## 为什么不保存完整微观路径

持续保存每个事件经过的节点和边，会让长期历史容量同时随实体数、事件容量和图规模增长，并把引擎变成主体内部全链路的外部录像机。v0.112 仍坚持 v0.111 的分层：连续 token 承担有界长期表征，局部 eligibility 只在图元素上短期存在。

## 下一授权边界

下一阶段应先冻结 Stage 3B-2 delayed association/modulation 合同，至少回答：

1. 图如何在不使用固定价值语义的前提下匹配历史 token 与后续客观事件；
2. 如何允许事件保持未归因；
3. 如何只调制仍存活的局部 eligibility；
4. 哪些通用图参数允许更新及其边界；
5. 如何防止同 tick 自证、无限历史和无成本塑性。

在该合同冻结前，不授权任何实际参数更新。

## 科学证据边界

本轮只能证明短期局部活动载体存在、衰减、到期、生命周期和 checkpoint 正确，并且相对 Stage 3A 行为及 RNG 中性。不能把它描述为归因、学习、记忆、价值形成、念头理解或主体性证据。
