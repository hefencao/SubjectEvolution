# v0.103 D1-V：独立信号介质与直接冲突接入边界

## 1. 本轮问题

D1-U 把地形同时作为移动阻力和通信阻力，强制两者同向。该简化无法表达高地难走但视野开放、低地易走但遮挡严重等组合，也会限制后续环境多元性。用户同时要求评估加入直接冲突。

## 2. 前置证据

上传的 D1-U 同 seed 对照中，CPU 与 GPU-hybrid 均完成修正后的竞争语义：各记录 18 次重叠需求事件，额外竞争能量和完整性损伤均为零。终点 alive 分别为 55 和 53，均不具备人口资格。因此本轮只允许物理字段和动作合同调试。

## 3. 实现

新增独立 `signal_openness` 环境字段。`terrain` 保持只影响移动；场信号和直接消息可选择读取 openness。两个字段分别配置 schema、幅度、周期、波向和相位。D1-V 地图故意设置为高移动阻力与高信号开放度同相，用于证明“难走但看得远”可表达；测试同时证明相位反转后可负相关。

旧配置默认禁用新介质，并保持旧协议身份。checkpoint、clone、CPU/GPU 环境镜像、报告边界和直接消息路径均接入新字段。

## 4. 直接冲突评估

直接冲突值得加入，但不应复活“相邻采集自动扣血”。推荐第一版为显式低致死 `INTERFERE`：动作占用、局部目标、发起成本、失败概率和有限物理结果都必须注册；结果只允许有限位移、当前采集中断或少量携带物散失。不得按 group、谱系、基因或预设角色加成。

v0.103 不启用该动作。原因是人口底座不合格，策略输出宽度和遗传坐标需要版本化迁移，且目标、成本、结算、信号和后端合同尚未完成资格验证。

## 5. 调试结果

新 seed 103011 完成 tick 240，终点 alive 107。场信号与直接消息均使用独立 openness schema；移动阻力与 signal openness 都具有非零空间方差。该地图的相关系数约为 +1，说明两者虽然在该实例中同相，却已不再共享一个字段；相位反转测试可得到负相关。

## 6. 证据边界

本轮只能证明移动阻力和信号介质已经解耦。特定地图上的相关性不是信息收益、社会分工或生态位证据。禁止正式环境 panel、直接冲突运行、基因审计、斥候角色、选择和适应解释。

## 7. 交付验证

需执行全量测试、配置与 workflow 加载、editable/entry point、CPU parity、可用时 GPU parity、隔离构建安装、外部 smoke、补丁重放和逐文件哈希比较。D1-V 只运行一个 CPU 传输语义 probe，结果包默认不含 checkpoint。
