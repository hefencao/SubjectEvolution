## 2. 输入与拒绝门

本轮只读取 Stage 3C-40 checksum-bound assessment 与 categorical trace。审计支持在看到 Stage 3C-41 结果前已经由 Stage 3C-40 固定为每个 source 的 top-five boundary opportunity，合计 18 个 source、90 个事件；全部 crossing event 必须包含其中。

拒绝条件包括：trace manifest 或文件 checksum 不一致、事件缺失、action mask 改变、random key/draw 改变、probability mass 不守恒、endpoint contribution 无法精确求和，或 crossing support 与 Stage 3C-40 不一致。

## 3. 分解定义

对原 sampled action `a`：

- lower endpoint 是 `sum(p_j, j<a)`；
- upper endpoint 是 `sum(p_j, j<=a)`；
- lower endpoint 朝 draw 的 pressure 是 lower CDF 的增加；
- upper endpoint 朝 draw 的 pressure是 upper CDF 的减少。

每个 action 对 endpoint 的贡献直接由其 probability delta 求和，不引入拟合权重。若 extended 条件下 active endpoint 与 horizon 最近端点不同，单独记录 endpoint-switch offset。

## 5. 冻结结果

### 5.1 唯一直接 logit source 是 REST

130 个非零 masked-logit comparison 全部只有 action index 0（`REST`）变化。`MOVE_RESOURCE`、`MOVE_SOCIAL`、`HARVEST`、`SHARE`、`SIGNAL`、`REPRODUCE` 和 `FLEE` 的 logit delta 均为零；其 probability delta 全部由 softmax 归一化耦合产生。

这说明 policy-level CDF pressure 的直接源已经收窄到 fixed bootstrap graph 的 `REST` output port，但不表示 REST 具有奖励、静息偏好或价值含义。

### 5.2 Crossing 同时包含正负 REST delta

六个 crossing mode-event 中：

- 正 REST logit delta：3；
- 负 REST logit delta：3；
- 其他 action probability 对 REST driver 形成净抵消：5；
- extended active endpoint 与 horizon 最近端点发生切换：2。

正 REST delta 会增加 REST probability，并可能把较后 action 的 lower CDF endpoint 向 draw 推进；负 REST delta 会释放 REST mass，其他合法 action 吸收该质量，并可能使 selected action 的 upper endpoint 向 draw 回落。

### 5.3 Softmax 抵消不可忽略

在五个 crossing 中，REST probability driver 大于最终 active endpoint pressure，差额由 selected action 之前或之内的其他 action probability 变化抵消。只有 `12305` 的 `MOVE_RESOURCE→REST` crossing，其 lower endpoint 只由 REST probability 构成，没有中间 action 抵消。

### 5.4 Alignment-common 与 alignment-specific

Seed `12307` 的 aligned 与 alignment-ablated pressure 绝对差仅 `2.4545e-08`，两臂具有几乎相同的 REST delta 与 probability redistribution，因此属于 alignment-common crossing，并继续被 cross-mode contrast 消去。

`12305、12308` 的 crossing 只出现在特定 alignment mode，或两种 mode 的 selected action/endpoint pressure 不同，保持 Stage 3C-34/40 的 alignment-specific identity。

### 5.5 幅度不能单独分界

- crossing 最大 `|REST logit delta|`：`0.1220562458`；
- noncrossing 最大 `|REST logit delta|`：`0.1698670387`；
- crossing 最大 `|REST probability delta|`：`0.0048640080`；
- noncrossing 最大 `|REST probability delta|`：`0.0296926668`。

所以 REST logit/probability 的符号或幅度都不能单独隔离 crossing。

独立 panel 最高机会来自 seed `12401`：REST probability driver 为 `0.0080366236`，其他 action 净抵消 `-0.0037461221`，最终 pressure 为 `0.0042905015`；原余量 `0.0062318283`，压力/余量比 `0.6884819850`，仍未 crossing。
