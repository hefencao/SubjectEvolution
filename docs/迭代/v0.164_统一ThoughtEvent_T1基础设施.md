# v0.164 统一 ThoughtEvent T1 基础设施

任务：`[EVOLVE-SUBJECT] subject-vm: establish unified ThoughtEvent chain substrate`

## 边界

本轮只建立思维链与较长期记忆共用的事件基础设施，不接入前向 recall、read head、语言、SignalEvent 世界频道、`RETHINK`、`NO_ACTION` 或 confidence gate。

## 实现

- 新增默认关闭的 `thought_event` 配置 sidecar；启用要求 Stage-3-or-later continuous token trace。
- ThoughtEvent 核心复用同一次权威 activation 产生的 token vector 和 objective-event identity，但不存 action、Objective-Fact、value 或 modulation 结果。
- 新增有界 per-subject arena、稳定 identity、parent DAG prefix、expiry、reactivation/reference 观察字段和计数成本。
- parent 必须同 subject、已保留且早于 child tick；禁止 self/same-tick/cross-subject parent，并避免 child append 覆盖其 active parent。
- 当前 runtime 自动事件 parent_count 固定为 0；T1 不读取 arena，不产生 recall 或运行时反馈。
- arena 随 checkpoint/clone 保存；出生不继承、死亡释放、compaction 随主体移动。
- 启用配置进入 configuration/checkpoint/branch identity；禁用精确默认值从 canonical configuration 移除，保持历史实验身份。

## 解释边界

计数成本只记录 emission、coordinate、parent-link 和 retention 工作量，不从 energy 扣除，不代表价值、重要性或长期保留资格。硬 age ceiling 是有界存储安全措施，不是认知上的“遗忘规则”。

## 下一项

T2 只读审计当前 token 的频率、重复度、漂移、arena occupancy、expiry/overwrite、成本和跨 source 差异。在 T2 资格通过前不接入前向 recall。
