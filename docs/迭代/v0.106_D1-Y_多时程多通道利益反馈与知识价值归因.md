# v0.106 D1-Y：多时程多通道利益反馈与知识价值归因

## 科学问题

D1-X 的 `received / (given + received)` 只能描述一个结算窗口内的物质回馈比例，不能代表完整利益。知识、预警、保护、冲突协助、机会成本和更晚的存活后果都是进入利益反馈网络所需的物理输入，不能因为当前仍是 Epoch 0 就推迟实现。

## 本轮实现

D1-Y 新增 `delayed-multichannel-interest-v2`：

- D1-X 的物质给予与接收保留为短时程通道；
- 转移知识副本保留来源 subject ID；
- 接收者以后执行匹配动作并获得真实五维后果时，才验证副本原先预测；
- 预测误差按既有 outcome scale 归一化，形成 `[-1,1]` 的有符号质量；
- 验证前置信度作为证据权重；
- 副本创建到验证的 tick 差作为延迟；
- 知识通道使用独立窗口、最小证据量和学习率结算；
- 物质与知识原始证据保持分离，不由单一公式代表全部伙伴价值。

知识预测准确只证明可验证信息质量，不证明接收者实际使用了知识或获得存活、繁殖和资源收益。更强结论仍需共享 checkpoint 下中和知识可用性或 policy 路由。

## 新暴露的结构债务

当前关系表仍以活实体行作为目标索引。知识副本能够保存稳定来源 subject ID，但来源死亡后不能把证据安全写入可能已复用的实体行，因此只能记为 orphaned evidence。下一步必须将长期伙伴记忆与活实体目标索引分离，按稳定 subject ID 保存历史关系，并明确定义死亡保留、后代继承、容量淘汰和区域分支规则。

## 授权边界

允许继续实现保护、冲突协助、机会成本和后续生存影响等独立后果通道，并建立历史主体关系存储。

不允许冻结 Epoch 1 base、启动 group 规章、运行正式主体性 panel、恢复基因审计或解释选择与适应。
