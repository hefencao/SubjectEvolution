# v0.109 D1-Z：分区统一主体图 Stage 2 激活适配器

## 本轮性质

本轮在 v0.108 惰性容器上实现 `partitioned-subject-graph-vm-v1` 的 Stage 2 CPU 参考路径：冻结通用输入/输出端口，执行有界、确定性的节点与边前向路由，并把输出接入现有 action logits。

本轮仍不实现后果 usage trace、资格传播、延迟可塑性、结构突变、发育表达、物理成本扣除或主体性实验。

核心边界：

> 行动接线只能证明统一图具有通用行为干预能力，不能证明任何具体认知、利益、知识价值、关系或主体已经形成。

## 已冻结合同

新增：

```text
protocols/decisions/subject_graph_vm_activation_v1.json
```

合同固定：

- `objective-entity-input-ports-v1`：16 个客观标量输入；
- `action-potential-output-ports-v1`：8 个 action potential 输出；
- `bounded-phased-forward-routing-v1`：有界、分相位、无随机数的前向执行；
- Stage 2 仅支持 CPU reference；
- 使用成本只计数，不转换为实体能量或选择收益；
- 禁止固定 reward、trust、knowledge value、interest、group bonus 和角色语义。

## 实现内容

### 1. Stage-2 配置

`SubjectVMConfig` 新增版本化 `activation` 子配置。Stage 1 配置仍保持完全惰性；只有显式使用：

```text
partitioned-subject-graph-vm-stage2-activation-v1
```

并匹配冻结端口和执行 schema 时才允许激活执行。

禁用默认仍被 canonical normalization 精确移除，旧配置身份不变。

### 2. 通用端口

`src/se/subject_vm/ports.py` 构造固定 16 维客观输入：

- 常量 1；
- 归一化能量、完整性、繁殖状态；
- 四个本地资源坐标；
- 三个已有信号坐标；
- 平均不确定性；
- 四个现有 retained policy state 坐标。

这些坐标是引擎事实或状态，不附带正负价值解释。

输出是 8 维 action potential，按现有 `Action` 顺序映射，但不能绕过现有 SHARE、SIGNAL、REPRODUCE 等物理可行性 mask。

### 3. 通用节点与边执行

`src/se/subject_vm/activation.py` 实现四个角色中性算子：

- bounded linear；
- bounded tanh；
- bounded retained linear；
- bounded retained tanh。

执行规则：

- region/node update period 决定某 tick 是否更新；
- `node_activation_phase` 决定同 tick 内的因果顺序；
- zero-delay edge 只能从严格更早 phase 指向更晚 phase；
- one-tick edge 读取上一 tick 保留状态；
- 同 phase 节点互不读取当 tick 新值，因此不依赖数组遍历顺序；
- edge bandwidth、node clip 和 output clip 分别限制局部与总体幅度；
- 不消费 RNG；
- 不写 eligibility 或 plasticity。

### 4. 行动边界接入

`src/se/runtime/subject_vm_activation.py` 是 Simulation 与 Subject VM 之间的窄适配器。

Subject VM 输出被加到：

```text
genetic logits + knowledge logits
```

之后、现有物理 action mask 与 categorical arbitration 之前。没有新增第二套 controller、Action enum、intent、冲突仲裁或 world commit。

Stage 2 配置在 GPU backend 上会明确失败，不允许静默忽略图输出或伪称 GPU parity。

### 5. 使用量记账

checkpointed accounting 记录：

- structural node units；
- structural edge units；
- node execution units；
- edge transmission units；
- cross-region transmission units；
- output contribution units。

这些只是工程计量，不扣除物理能量。真正的 structural/runtime/memory/bandwidth/plasticity 成本必须在 Stage 4 单独冻结。

### 6. 生命周期和兼容

新增激活绑定字段随结构继承；动态 node state 仍在出生时清零。

checkpoint schema v2 保存：

- input/output bindings；
- bias、retention；
- dynamic activation state；
- activation accounting。

v0.108 Stage-1 runtime/storage payload 可恢复，新字段填充为惰性默认，不伪造 Stage-2 行为。

## 验收测试

新增测试覆盖：

- Stage-2 配置和 CPU-only device contract；
- 手工图的确定性有界 action potential；
- retained operator 与 one-tick edge；
- zero-delay phase 安全；
- Stage-2 empty graph 精确中性；
- Simulation → Subject VM → existing policy 接线；
- checkpoint state/accounting round trip；
- v0.108 Stage-1 payload 升级兼容。

短程 smoke 只能证明：

- 图执行器可工作；
- 输出进入现有 policy；
- 状态和计数可恢复；
- 空图不改变行为。

发布验证结果由 delivery manifest 和 validation report 记录，不写入稳定迭代文档。测试工具链同时修复了并发子进程输出管道可能互相阻塞的问题；`conda-check` 新增环境前置检查，避免误用指向其他 checkout 的陈旧 editable 安装。

手工图改变 action logits 是工程能力，不是涌现证据。节点状态、跨区传输和行为变化都不能被直接命名为感知、记忆、利益、知识、信任、决策或主体控制。

D1-X/Y 继续保持：

```text

retained-as-fixed-cognition-baseline
```
