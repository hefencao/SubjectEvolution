# v0.84 ecosystem implementation

This release continues the `PROJECT_CHARTER` mainline of effective environment
construction and inherited carrier capability while portfolio/candidate audit
expansion remains paused.

D1-D's supplied three-seed shared-checkpoint calibration is retained as a valid
mechanism result: inherited resource-sensing radius reaches the observation
boundary, the radius-one intervention preserves genotype and registered costs,
and the paired run authorizes no ecological or selection claim. The consistently
negative short-window outcome is treated as evidence that the archived
non-persistent resource substrate did not maintain enough exploitable scale
structure, not as a reason to add rewards or tune a preferred radius.

D1-E adds `persistent-multiscale-four-resource-renewal-v3`. The existing four
resource channels receive distinct primary toroidal scales, secondary modes,
cycle periods, phases, and diffusion rates. Moving-target renewal maintains the
scale separation without entity, lineage, group, or result feedback. CPU and
device paths expose the same configured scale semantics.

The active D1-E run chain is stored under
`studies/d1e_persistent_multiscale_resources_v1/commands/`. It remains a
three-seed source and cost-preserving paired calibration with no pass/fail gate.
Each active study also provides `commands/90_pack_results.sh`, which creates a
deterministic manifested handoff bundle and includes checkpoint bytes only when
`INCLUDE_CHECKPOINTS=1` is explicitly requested.

Complete release packages retain this current-version directory, `docs/v0.84/`,
and remove older iteration directories. Durable cross-version conclusions remain
in the canonical project documents under `docs/`.
