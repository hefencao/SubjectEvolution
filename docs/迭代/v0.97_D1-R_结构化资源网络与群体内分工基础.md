# v0.97 D1-R：结构化资源网络与群体内分工基础

## 科学任务纠正

D1-Q 正式 panel 据用户报告无一 seed 通过。此前继续做稳态门、遗传收缩
分类或单轮审计，都会在环境尚不足以产生多元结构化主体时把环境缺陷误写成
基因结论。本轮停止所有活跃遗传存续审计，将主线改为环境成熟度建设。

最低环境门槛不再是“有四种资源”或“检测到 group”，而是完整主体在多个
独立 seed 中形成可存续的多个群体，并在群体内部持续出现由物理链导致的
采集、运输/交换、加工和协调差异。

## 共享物理变化

D1-R 不修改遗传坐标、突变、维护、繁殖或角色奖励，新增：

- 四个分离且周期变化的原料供给省区；
- 与供给省区错位的加工省区；
- 四个至少需要两种原料的互补加工配方；
- 按供方盈余和受方容量结算的原料 SHARE；
- 由成功交换支持、统一衰减的既有关系图；
- 不反馈世界的群体功能观测层。

旧配置默认保持原独立转换和纯能量分享语义；新字段在禁用默认状态下不改变
旧冻结研究身份。

## 分工诊断

诊断按 120 tick 固定窗口记录成员实际完成的四通道采集、四配方加工、
原料发送/接收、能量分享、信号和社会移动。候选群体必须满足：

- 至少 6 个成员在窗口内保持不少于一半时间；
- 稳定成员参与率不少于 75%；
- 稳定成员平均在群时间不少于 65%；
- 功能有效维度不少于 2；
- 至少 3 个不同主导功能；
- 成员平均专门化不少于 0.18；
- 至少两条配方实际运行；
- 存在真实群内原料交换；
- 群内交换依赖不少于 1%。

群体 token 由根成员导出，根成员死亡会改变 token。因此持续性不再直接按
token 判断，而是以稳定成员集合 Jaccard 不少于 0.40 且至少 3 个共同成员
追踪群体谱系。候选必须连续至少两个窗口。

## 探索证据

冻结 seed 97011 仅为环境参数调试：tick 600 时 alive=91、groups=5、
grouped fraction=0.451、累计群内原料交换=27.379。物理资源字段和区域
signature 均明显多维。诊断识别 1 个连续两窗口的分工候选群体谱系，并曾在
一个窗口同时出现 3 个候选。

该样本没有达到每 seed 至少两个持续候选群体的正式门槛，不能证明环境已经
成熟，更不能支持遗传、适应、生态位或社会角色结论。

## Workflow

活跃 study 为 `studies/d1r_structured_environment_division_v1`：

- `prepare-config`
- `environment-probe`
- `probe-summary`
- `structured-panel`
- `structure-summary`
- `pack-results`

其中单 seed `environment-probe` 永远只产生调参证据。workflow 不声明
`gene-persistence`、遗传 retention、paired 或 candidate ledger 步骤。

## 证据边界

v0.97 只证明新物理链和观测链可运行，并找到一个尚未达到正式门槛的候选
参数区间。下一步是三个独立 seed 的结构化环境 panel。无论单个 probe 多么
“好看”，都不能触发基因修改或单轮审计。
