# v0.124 D1-Z：主体图 Stage 3C-10 漏斗与可见性诊断

## 本轮决策

v0.124 选择路径 A：补齐诊断和实验可观测性，不修改学习机制，也不调整任何主要实验变量。原因是 v0.123 已证明配对数据链完整，但 0/21 稳定坐标尚不能区分“链路未进入”“临时写入未影响行为”“行为改变未跨离散采样”“客观窗口过短”或“固定 bootstrap 可达性过窄”。

版本继续使用原 Stage 3C-9 对照：seeds 12301/12302/12303，source tick 2，branch horizon 5，16 个 fixed-bootstrap subjects，32 个初始实体，CPU，永久保留关闭。总运行规模为每 seed 2 个 source tick 加 live/control 各 5 tick，属于短程探索，不需要大规模本地长跑。

## 实现

新增 `se.analysis.subject_vm_stage3c10_diagnostics` 与 `se-subject-vm-stage3c10-diagnostics`。study runner 在 Stage 3C-7 和 Stage 3C-8 后生成 `stage3c10_diagnostics.json`，报告：

- source/subject 漏斗与每主体窗口分布；
- 原始拒绝原因和用户要求的规范拒绝类别；
- raw、bounded、projected delta 及参数范围比例；
- 每个参数族、目标类型、区域的提案/写入分布；
- 临时参数实际覆盖的语义 tick 和主体事件；
- eligibility value/age、association delay/similarity；
- 历史事件重复关联和 target 重复绑定；
- live/control 首次分化 tick、结构和逐 tick 时间线；
- source identity、准入、事务成本、evaluation cost、窗口数量、回滚和 finalization 对称；
- 参数精确恢复与回滚后的非参数路径依赖；
- subject-balanced、window-weighted、median、nonzero source/subject 和窗口不平衡诊断。

运行时新增两个固定容量字段：

```text
association_reason: uint8[E, C]
binding_eligibility_age: uint16[E, C, 6]
```

新增内存：

```text
E*C*1 + E*C*6*2 = 13*E*C bytes
```

当前 E=32、C=16 时为 6,656 bytes。字段仅在关联/target binding 启用时分配；旧 v0.123 trace schema 缺失字段时按零恢复。没有新增配置字段，因此 disabled canonical identity 和旧配置 hash 不变。没有保存完整逐 tick 节点/边路径。

## 真实诊断结果

同一三 source 重跑继续得到 38 个 completed paired windows、pairing coverage 1.0、rollback failure 0、objective fact clipping 0、evaluation cost match 1.0。未发现 branch identity、control reservation、window symmetry、rollback 或 export-boundary finalization 合同错误。

漏斗不是在激活层断裂：所有 16 个 bootstrap subject 在每个 source 都生成 token。每 source 有 80 个 token event、64 个 association assignment，最初 16 个事件因无历史候选而不分配。所有 64/64 assigned association 的 delay 均为 1、similarity 均为 1.0，表明当前 fixed nearest-token bootstrap 的候选竞争退化为最近同形 token。

三个 source 分别形成约 54–60 个 modulation proposal、38–42 个 safe update 和 15 个 live commit/control reservation。121 个安全提案与 45 个临时写入全部属于 `node_bias`，其他五个参数族为零。绑定时 eligibility 绝对值中位数约 0.375，age 为 1；没有证据表明 eligibility 在绑定前普遍衰减到接近零。

bounded/projected change 的绝对值中位数约 0.023–0.033，最大 0.1；相对配置参数范围通常约 0.6%–0.8%，最大 2.5%。由于 commit 在本 tick 激活后发生、rollback 在 due tick 激活前发生，`rollback_after_ticks=2` 实际只覆盖一个后续语义激活 tick。

临时写入在三个 source 都从 commit 后的下一 tick 改变 action potential 和 sampled probability，共 120 个匹配主体事件出现参数层差异。然而只有 seed 12302 的两个主体事件改变离散 action，客观事件差异也只出现在该 source。三个 source 的参数均精确恢复；seed 12302 在回滚后仍保留 energy/x/y 非参数状态差异，因为已经发生的动作改变了世界轨迹。

Stage 3C-8 的 subject-balanced 主统计保持不变。window-weighted、median、nonzero source count、非零主体比例和窗口不平衡只作为诊断；没有把窗口提升为独立 replicate，也没有过滤零结果。

## 允许与不允许的结论

允许：

- 数据生成、配对、回滚和清算合同完整；
- 当前 fixed bootstrap 的 association 与参数族覆盖高度集中；
- 临时写入能影响连续行为量，但多数影响没有跨过离散 action 采样边界；
- 当前短程客观事实信号稀疏主要发生在参数影响到离散行为/世界事件之间，而非 token 链完全未激活。

不允许：

- 更新有效或无效；
- 已形成稳定学习或因果信用；
- `node_bias` 是正确或唯一学习参数；
- nearest-token 是通用注意力；
- 应永久保留参数、自动 keep/revert 或建立 scalar reward；
- 应立即切换完整通用注意模型、拓扑演化、大规模长程或 Epoch 1 panel。

## 下一边界

v0.124 不实施下一变量。后续单独版本可在保持原 v0.123 对照和三个独立 source 的前提下，一次只比较一个因素。根据本轮证据，优先候选是临时作用覆盖（rollback/evaluation horizon）或固定 bootstrap 的参数族可达性，但必须在新版本中明确选择其一并重新运行 Stage 3C-7、3C-8、3C-10。即使出现同号坐标，也不自动授权永久保留。
