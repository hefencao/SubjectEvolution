# v0.136 D1-Z：主体图 Stage 3C-22 历史事件选择覆盖与复用审计

## 目标

Stage 3C-21 已证明一个现有 objective readout 能产生主体/事件特异 token geometry，但它没有增加 commit、客观分化或稳定坐标。本轮不修改运行时，而是回答：新 geometry 是否扩大了可选或实际被选的历史事件身份集合，还是只重新排序并集中复用同一候选机会。

## 分析合同

复用 Stage 3C-21 的 constant-one 与 uncertainty-mean 两个九 source arm。分析器从 read-only control checkpoint 中逐 query 重建同主体、delay 1–6、非零、normalized-dot similarity≥0.8 的完整候选机会，并使用现有 latest/top-1 selector复算存储选择。相似度、threshold、top-k、tie-break、target、carrier、delta、exposure、rollback 与永久保留状态均不改变。

最高独立重复仍是 pre-bootstrap source checkpoint。事件、主体和窗口只能作为 source 内部覆盖，不能当作独立 replicate。

## 真实结果

两个 arm 每 source 都具有完全相同的候选机会：112 个唯一 above-threshold 历史事件、432 个 above-threshold references、112 个已分配 current events。所有 delay-valid reference 都非零，所有非零 reference 都通过 threshold；存储选择与生产 selector 逐事件复算零不一致。

Constant latest-on-tie 基线每 source 选择全部 112 个历史事件，各使用一次，coverage=1.0、maximum reuse=1、Gini=0、inverse-Simpson effective count=112。

Uncertainty arm 每 source 只选择 85–94 个唯一事件，覆盖率 75.9%–83.9%，留下 18–27 个可选身份未使用；maximum reuse=3，eligible-union Gini 为 0.272–0.381，inverse-Simpson effective count 仅相当于可选集合的 64.4%–74.7%。九个 source 中 uncertainty 的 selected set 都是 constant set 的严格子集，没有增加任何 constant 未覆盖的新事件身份。同 query 选择完全一致的比例为 52.7%–71.4%。

选中客观事实向量的 centered rank 在九个 source 中均未下降，因此身份覆盖减少不能等同于客观事实线性空间完全坍缩。

## 结论边界

主体/事件 geometry 改变的是候选排序，不是候选资格；在当前 latest/top-1 工作点，它增加了历史事件复用集中度，并未增加 selected identity diversity。Constant 的全覆盖也只是 delay-1 latest 基线结构，不具有“更好”的固定价值语义。

本轮不授权因果 credit、学习、永久写入、自动 keep/revert、scalar objective、主体性或通用注意力声明。

## 下一边界

固定 uncertainty readout、normalized-dot similarity、latest top-1、target/carrier、delta、exposure 与 rollback，只读筛查第二个无角色价值语义的 visible coordinate；只有在主体/事件特异 geometry 达到 rank 2 后，才考虑 paired addressing 变更。
