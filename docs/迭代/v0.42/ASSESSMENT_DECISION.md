# Decision from the supplied D2-C assessment

The supplied assessment contains six checkpoint conditions at 120/300 ticks.
Immediate footprint refresh succeeded for every fixed module, and every module
has material footprint in multiple lineages. Modules 1, 2 and 3 have repeated
ecological effects; modules 2 and 3 each have repeated positive extraction-
efficiency effects.

The source population nevertheless remains lineage concentrated:

- median effective lineages: `2.0260`;
- minimum effective lineages: `1.5744`;
- dominant-lineage risk: `true` against the preregistered threshold `4.0`.

Therefore:

- module duplication, deletion, arbitrary routing and new output ports remain
  blocked;
- the missing evidence is not immediate cross-lineage reach;
- the next experiment is a shared-checkpoint, lineage-balanced paired audit;
- modules 2 and 3 are the first priority because their repeated mechanistic
  effect is directly tied to extraction efficiency;
- output effects and expression-cost refunds must be separated.

No source checkpoint from the supplied assessment is bundled with this project,
so the full 120-tick D2-D matrix is not rerun in this delivery. The new command
is executable against the existing local D2-B result/checkpoint tree.
