# v0.140 D1-Z：主体图 Stage 3C-26 年龄、阶段与机会归一化审计

## 目标

在不修改 runtime 的前提下，复用 Stage 3C-23 冻结 rank-two 面板，区分 winner 复用中的 source-boundary 强制分配、历史事件年龄、query phase、原始候选机会和 opportunity-normalized basin occupancy。

## 实施

新增 `se-subject-vm-stage3c26-age-phase-opportunity` 分析器、决策协议、声明式 workflow 与回归测试。分析器逐 query 重建同主体、delay 合法、非零且高于 threshold 的全部候选，并精确复核 stored winner ID 与 similarity。

本轮不修改 similarity、threshold、latest/top-1、candidate limit、target/carrier、delta、exposure、rollback、checkpoint schema 或永久保留。持久内存增长为 0。

## 九 source 真实结果

- 每 source 128 个 request；16 个无历史候选，112 个完成 assignment。
- 首批 16 个 assignment 只有一个候选，占全部 assignment 的 1/7，并保证 16 个 phase-zero event 各被选择一次。
- 排除这些强制 assignment 后，age-one selection/opportunity 为 0.375–0.5625，在 9/9 source 中最高或并列最高，8/9 source 严格最高。
- reused winner 的 historical-phase 中位数为 0–1；single-use 为 3–4；unselected eligible event 为 4–5。
- reused winner 的 selection/opportunity 中位数在 9/9 source 中不低于 single-use，在 8/9 中严格更高。
- 工程基线仍为 pairing coverage 1.0、零 rollback failure、零 fact clipping、matched evaluation cost 和 0/21 stable objective coordinates。

## 结论边界

source-boundary 强制分配和较长机会窗口确实贡献早期事件覆盖与复用，但 raw opportunity 不能完全解释持续的 age-one basin。该结果不为年龄、近因或 query phase 赋予价值，不验证 causal credit，不建立学习或主体性，也不授权 permanent retention。

下一边界是在全部运行合同不变时，只读区分 age-one basin 来自 score geometry、latest tie-break 还是 branch-boundary support，然后再决定是否需要任何机会或年龄归一化。
