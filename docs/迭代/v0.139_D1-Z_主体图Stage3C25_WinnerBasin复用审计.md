# v0.139 D1-Z：主体图 Stage 3C-25 Winner Basin 复用审计

## 1. 本轮问题

Stage 3C-24 已经证明：rank-two readout 消除了 exact winner tie，但没有扩大 eligible historical-event identity，并且 selected identity coverage 进一步下降。

本轮继续回答：

> Rank-two arm 的重复 winner 主要由极小但非零的 best-second margin 造成，还是由 bounded delay opportunity 与跨 query 的 deterministic candidate basin 造成？

本轮不修改 addressing、similarity、threshold、top-k、tie-break、target、carrier、delta、exposure、rollback、实体规模或永久保留。

## 4. 正式九 Source 结果

每 source：

```text
assigned queries: 112
multi-candidate assigned queries: 96
unique selected winners: 80..88
reused winners: 21..27
assignments to reused winners: 41.1%..52.7%
```

Winner selection count 最大为 4。Reused winner 的 query tick span 为 1–5 tick。

### 4.1 Absolute margin

Best-second absolute margin 不超过 `1e-3` 的 multi-candidate query 比例为：

```text
59.4%..76.0%
```

因此数值间隔整体偏小，不能宣称 score ordering 非常稳健。

### 4.2 Score-spread-normalized margin

但 reused-winner assignment 的 normalized margin 中位数为：

```text
0.0590..0.7980
source-balanced median: 0.2792
```

Single-use winner 的 normalized margin 中位数为：

```text
0.000395..0.01914
source-balanced median: 0.00410
```

9/9 source 中，reused winner 的 normalized margin 中位数都更高。

Absolute margin 不超过 `1e-6` 的比例也在 9/9 source 中对 reused winner 更低：

```text
reused winner: 4.9%..15.4%
single-use winner: 34.7%..51.8%
```

因此 winner 复用并不集中在最弱的相对 score margin。

### 4.3 Query geometry

所有 112 个 assigned query 在每个 source 中都有不同的 exact visible query vector。

每个 reused winner：

- 对应不同 query event；
- 对应不同 exact visible query vector；
- 可跨多个 query tick；
- 不是 query token 完全重复造成。

Same-winner query pair 的 median cosine 在 9/9 source 中不高于 same-subject different-winner pair。这不意味着 geometry 无关，而是排除了“winner 复用仅因为 query 自身重复或更相似”的简单解释。

### 4.4 Candidate opportunity

Reused winner 的 eligibility opportunity 中位数在所有 source 都是：

```text
6
```

Single-use winner 的中位数为：

```text
3..4
```

因此早期历史事件在 bounded delay window 中拥有更多后续 query 机会，并可能形成覆盖多个不同 query 的 deterministic nearest-neighbor basin。

## 5. 结论边界

本轮允许得出：

> Small absolute margins are common, but rank-two winner reuse is not concentrated in the smallest normalized margins and is not caused by exact duplicate query vectors. It is consistent with opportunity-conditioned deterministic candidate basins.

本轮不允许得出：

- candidate basin 更好或更坏；
- 较大 margin 更有价值；
- 更多 opportunity 应获得补偿或惩罚；
- credit assignment 正确；
- 已形成学习或主体性；
- 应增加 top-k 或 learned weights；
- 应永久保留参数；
- normalized-dot 是通用注意力。

## 6. 下一边界

下一步应继续固定 Stage 3C-23 rank-two readout、normalized-dot、threshold、latest/top-1、target/carrier、delta、exposure 和 rollback，只读审计：

- historical age 与 winner basin occupancy；
- query phase 与 opportunity-normalized selection rate；
- 复用是否主要来自 bounded delay window 的年龄机会不均衡。

在此之前不修改 addressing，也不引入 reward、learned weights 或永久保留。
