# v0.113 D1-Z：主体图 Stage 3B-2 有界延迟关联候选

## 本轮定位

本轮在 v0.111 连续内部 token、客观事件 ring 和 v0.112 短期局部 eligibility 之上，只实现延迟关联的**候选寻址**。它不解释客观事件，不调制 eligibility，也不更新任何图参数。

核心边界：

> 连续 token 相似度只能回答“图请求后，哪个较早内部表征可作为候选”；它不能回答“哪个历史真正导致当前后果”，更不能回答“当前后果是好还是坏”。

## 已实现

### 配置

新增：

- `partitioned-subject-graph-vm-stage3b2-delayed-association-v1`；
- `bounded-delayed-token-similarity-candidate-v1`；
- `request_token_port`；
- `request_threshold`；
- `similarity_threshold`；
- `min_delay_ticks`；
- `max_delay_ticks`。

约束：

- `min_delay_ticks >= 1`，禁止同 tick 自证；
- `max_delay_ticks` 不得超过 token retention；
- `max_delay_ticks` 不得超过 local eligibility lifetime；
- disabled association 必须使用精确默认值并从旧配置 canonical identity 中移除；
- 配置不允许 reward、valence、polarity、trust、interest、knowledge value 或 hash algorithm 等具体语义字段。

### 图控制的请求

当前 token 的一个坐标作为通用请求门。它仍由图的普通 token readout 节点产生。

- 请求值低于阈值：当前事件保持未分配；
- 请求坐标从当前 query 和历史 candidate 中同时清零后再计算相似度；
- 因此提高请求门不能直接提高匹配分数；
- token 其他坐标的含义仍完全由图形成，引擎不命名概念。

### 有界候选搜索

只搜索同一主体 ring 中：

- 仍有效；
- 严格早于当前 tick；
- 延迟位于配置窗口；
- 不会被当前写入覆盖的历史槽位；
- 去除请求坐标后非零的 token。

使用确定性的 normalized dot similarity。并列时依次选择：

1. 更高相似度；
2. 更新的合格历史 tick；
3. 更小的稳定 event ID。

### 关联记录

当前事件仅增加：

- 是否请求；
- 是否分配；
- 历史 event ID；
- 历史 event tick；
- delay ticks；
- similarity。

不复制：

- 历史 token；
- objective event 向量；
- node/edge ID；
- activation mask；
- eligibility snapshot；
- 完整执行路径。

### 生命周期与兼容

- association metadata 只在 Stage 3B-2 分配；Stage 3A/3B-1 内存边界不扩张；
- birth 的新 ring 为空；
- death 清除；
- compaction 随稳定主体移动；
- clone 和 checkpoint 精确复制已提交关联；
- v0.112 Stage-3B-1 checkpoint 升级时重建空关联数组，不伪造历史连接；
- regional branch 继续使用既有统一生命周期。

## 明确未实现

- 把 similarity 当作 causal credit；
- objective event 的正负价值；
- event-to-eligibility modulation；

- node bias、input/output/trace gate、edge weight、retained state 或 topology 更新；
- graph-produced modulation signal；
- parameter target selection；
- update stability、plasticity cost 或 physical debit；
- GPU Stage 3 执行；
- Epoch 1 panel、主体性评分或涌现结论。

## 为什么不直接更新参数

当前候选只证明内容寻址基础设施成立。若立即把当前客观状态差乘到 local eligibility 上，就会把引擎定义的坐标隐式变成 reward；若把 similarity 直接当信用强度，则会把“相似”误写成“因果”。因此 v0.113 只保存可审计候选，不产生调制提案。

## 下一授权边界

下一阶段应冻结 Stage 3B-3 modulation-proposal 合同，至少回答：

1. 图如何从已提交候选和当前/历史客观事实产生可拒绝的通用调制信号；
2. 如何保证 current-tick eligibility 永远不能被同 tick 后果调制；
3. 如何只作用于仍存活的 local eligibility；
4. 哪些通用参数允许成为提案目标；
5. 如何限制单次和累计提案；
6. 如何把实际写入、稳定性和物理成本推迟到独立授权阶段。

在该合同冻结前，不授权参数写入。

## 科学证据边界

本轮只能证明：图可以请求一个有界、确定性、允许未分配的历史 token 候选，并经生命周期和 checkpoint 精确保存。它不能证明候选具有因果性、价值、记忆理解、学习效果或主体性。
