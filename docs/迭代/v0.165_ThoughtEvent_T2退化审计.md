## 目的

在接入任何前向 recall 前，验证 T1 arena 的身份、生命周期和成本，并判断当前 graph-produced token 是否存在完全重复、低秩塌缩或跨 tick 近静止。

## 预声明对照

- 负对照：readout ports `11, 11`；

- 两臂共享 source、action 路径、事件身份和世界状态；
- 不实现 read head、recall、retention policy 或新 runtime 机制。

## 结果

九 seed 负对照全部为 centered rank 1，并有 95.83%～98.44% 精确重复。候选每 seed 192 个事件全部精确不同且 centered rank 为 2，但连续同主体 token 的 cosine 中位数约为 0.99905～0.99910。

生命周期逐 seed 精确满足 192 次 emission、48 次 expiry、0 次 overwrite 和 144 个最终保留事件；parent_count 为 0。

## 结论

诊断工具和 arena 获得资格；候选 token 避免完全重复，但仍是低秩、高相似 fixed-bootstrap 表示。下一轮只允许 T3 最小前向 recall 机制 smoke，不允许把结果描述为思维链、分布式认知或语言。
