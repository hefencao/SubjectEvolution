# v0.108 D1-Z：分区统一主体图 Stage 1 惰性基础设施

## 本轮性质

本轮实现 `partitioned-subject-graph-vm-v1` 的 Stage 1，只建立配置、固定容量存储、身份和生命周期基础设施。主体图不参与行动，不执行可塑性，不产生运行收费，不消费随机数，不触发主体性实验。

核心边界：

> 可以预设帮助网络塑形的通用计算区域和因果相位，但不能预设具体利益、知识价值、社会关系、角色或主观正负价值。

## 已实现

### 1. 独立包与配置

新增 `src/se/subject_vm/`：

- `config.py`：disabled-by-default 的版本化配置、四区域合同、禁止具体认知字段；
- `storage.py`：固定容量节点、边、区域、内部状态、激活元数据和未来资格元数据占位；
- `lifecycle.py`：出生继承、死亡释放、压缩和明确的无突变边界；
- `runtime.py`：禁用空对象、checkpoint/clone、兼容恢复和 CPU/GPU-hybrid 惰性契约；
- `__init__.py`：最小公共接口。

禁用配置被 canonical normalization 精确移除。`configs/mvp_small.json` 的冻结 canonical SHA-256 和 checkpoint config SHA-256 保持不变。

### 2. 惰性固定容量存储

启用时每个实体槽位具有统一节点/边身份空间，节点和边按四个初始区域预留容量。存储包括：

- owner entity ID 与 stable primary subject ID；
- 节点 ID、表达门、区域、通用 operator ID、内部状态、更新周期和相位；
- 边 ID、表达门、区域、source、target、forward gate、delay、bandwidth 和 phase mask；
- eligibility value/age 与 plasticity flags 占位；
- 按区域计算的容量和实际表达使用统计。

所有节点和边初始未表达。Stage 1 不遍历执行它们，不写资格痕迹，不产生 action potential，也不收费。

禁用时只保留极小 runtime wrapper，不分配节点、边或内部状态数组。

### 3. 生命周期

- 初始实体在 stable subject ID 注册完成后绑定图行；
- 新生实体继承父代结构、区域、拓扑和路由元数据；
- 新生实体不继承运行中内部状态或资格痕迹；
- Stage 1 mutation plan 只接受 `none-v1`，没有新增突变分布；
- 死亡前按 entity ID 和 subject ID 核验所有权并清空图行；
- 槽位复用不会附着到旧主体；
- 提供显式 row-compaction hook，不建立第二套实体生命周期；
- regional branch 删除外部实体时同步释放主体图行。

### 4. checkpoint、clone、epoch base 和兼容恢复

完整 checkpoint 保存显式 Subject VM snapshot；clone 深复制所有数组。epoch base 因复用完整 checkpoint 自动包含图状态。

恢复缺少 Subject VM 字段的兼容 checkpoint 时：

- disabled 配置恢复为无存储空对象；
- enabled 配置按当前存活实体和 stable subject ID 重建全空 Stage-1 容器，并标记 `compatibility-empty-rebuild`；
- 不伪造表达节点、边、内部状态或可塑性历史。

### 5. CPU/GPU-hybrid 合同

Stage 1 状态为 host-authoritative：

- 不分配 device graph state；
- 不进行 host/device graph sync；
- 不参与 GPU kernel；
- 不消费 RNG；
- 不影响 action、成本或世界结算。

这是一项显式的惰性合同，不表示 Stage 2 已具备 GPU packed representation。

## 中性验证

已增加测试验证：

- disabled 配置身份和旧 checkpoint config hash 不变；
- 禁用时无大型存储；
- enabled-but-empty 与 disabled CPU 路径连续多 tick 的实体、环境、信息、社会和动作计数完全一致；
- checkpoint round trip、clone 和缺字段兼容重建；
- 出生结构继承、动态状态重置、死亡清理、压缩；
- regional active-set branch 后图 occupancy 与实体 alive 完全一致；
- 架构行数门不放宽。

短程 smoke 只能证明状态存在、可恢复、生命周期正确和中性路径不改变行为。

## 科学证据边界

本轮是工程基础设施，不是主体性证据。区域名称、图状态存在、checkpoint 可恢复、节点或边可表达，都不能被描述为感知、记忆、利益、知识、信任、决策或主体雏形已经形成。

D1-X/Y 保持：

```text
rejected-as-primary-subject-model
retained-as-fixed-cognition-baseline
```

## 版本结论

v0.108 完成 Stage 1 惰性容器。Stage 2 必须单独冻结输入/输出端口、通用算子、执行顺序和成本合同后才能开始；不得从本轮顺手启用。
