# v0.134 D1-Z：主体图 Stage 3C-20 可见 Graph-State Readout 可达性审计

## 1. 目标

Stage 3C-19 证明 association-visible ports 29-31 在当前 fixed bootstrap 中恒为 `[0,0,1]`。本轮只检验一个现有 graph state 是否能让 scorer 获得真实方差：将 action-producing node 0 当前状态映射到 visible port 29。

## 2. 固定合同

九个独立 source `12301..12309`，每 source 32 实体、16 bootstrap subject、source tick 2、branch horizon 8、exposure 3、CPU、`edge_forward_gate` carrier-on、latest、top-1、normalized-dot、bounded delta、自动回滚和无永久保留全部固定。

baseline 不启用 node-0 visible trace；alternative 仅设置 node 0 `trace_port=29`、`trace_gate=1.0`。该字段只属于显式 study bootstrap profile，不进入项目 config identity 或 checkpoint schema。

## 3. 隔离结果

九个 seed 的 pre-bootstrap state/config hash 和 selected stable subject 完全一致。read-only control 的 action potential、sampled probability、action、resolution 和 objective fact 逐事件一致；thought token 除 port 29 外逐坐标一致。

## 4. Geometry 与寻址结果

baseline 每 source 只有一个 visible vector、centered rank 0，全部 score 为 1.0。readout arm 每 source 有 7 个 visible vector、centered rank 1；score 范围约 `-0.5073..1.0`，best-second spread 为正，exact tie 消失。

但同一 tick 内所有 bootstrap subject 的 port-29 值一致，九个 source 也共享同一 tick trajectory。因此该 readout 是 fixed shared temporal phase，不是 subject/event identity。

实际 selected association 从 baseline 的 1008 个 delay-1 变为 readout 的 864 个 delay-2；unique historical event 每 source 从 112 变为 96，均无重复复用。

## 5. Paired evidence

baseline/readout 分别产生：

- modulation proposal：942 / 535；
- guarded-live commit：144 / 143；
- completed paired window：129 / 100；
- discrete action difference：4 / 2；
- objective-divergent source：3/9 / 2/9；
- stable objective coordinate：0/21 / 0/21。

两个 arm 均 pairing coverage 1.0、rollback failure 0、fact clipping 0、evaluation cost match 1.0。

## 6. 结论边界

本轮证明现有 graph state 可以解除 rank-zero 与 exact-score-tie 退化，但当前 readout 只编码共享时间相位。不得宣称 credit 正确、delay=2 更优、已学习、已形成主体性或应永久保留参数。

下一最小边界是一次只比较一个现有 factual/internal readout，目标是增加 subject/event-specific variance；similarity、candidate limit、delta、exposure、rollback 和 retention 必须继续固定。
