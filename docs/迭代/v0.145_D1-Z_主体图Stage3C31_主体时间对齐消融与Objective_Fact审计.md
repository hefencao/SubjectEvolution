# v0.145 D1-Z：主体图 Stage 3C-31 主体—时间对齐消融与 Objective-Fact 审计

## 1. 主线位置

`Stage 3C-30 权重/秩坍缩冻结 → 3C-31 同状态竞争筛查 → tick-wise subject donor 对齐消融 → 21 维 objective-fact 对照 → 九 source 冻结 → 发布验证`

本轮不增加 runtime 机制，不进入 learned weighting 或永久 retention。

## 2. 单一问题

第二 visible coordinate 的稳健同状态排序，究竟只需要其边际分布，还是依赖该坐标与具体主体历史的对齐？打断对齐后，被选择历史事件的客观事实对比如何逐坐标变化？

## 3. 隔离合同

- 共享 Stage 3C-23 rank-two source/checkpoint lineage。
- 验证 Stage 3C-30 checksum。
- 排除 16 个 source-boundary 单候选 query。
- 仅分析 baseline winner 同状态、且有至少两个同状态候选的 query。
- 每 tick 精确保留第二坐标 float32 multiset；donor 不得为自身，offset 随 tick 改变。
- raw-threshold candidate opportunity 与候选评估次数匹配。
- objective facts 不修改，21 个坐标分别报告。
- runtime/checkpoint/random stream/retention 均不改变。

## 4. 正式结果

九个独立 source 共得到 460 个同状态竞争 query，每 source 为 43–58。对第二坐标做主体—时间错位后：

- winner identity 改变比例为 39.53%–74.51%，source-balanced 中位数 60.34%；
- baseline age-one winner fraction 为 43.75%–62.79%，中位数 51.85%；
- 消融后 age-one winner fraction 为 17.65%–44.19%，中位数 22.92%；
- 每 tick 第二坐标 float32 multiset、无 self donor、候选评估次数匹配在 9/9 source 中全部成立。

因此，仅保留坐标边际分布不足以复现当前同状态排序；该坐标与具体主体历史的绑定是 fixed-bootstrap selector 的机械组成部分。

21 维 objective-fact 结果不是统一方向。每个 source 均同时存在正、负 mean paired delta；其中 9 个坐标在 9/9 source 中均为正的 `ablation absolute contrast - baseline absolute contrast`：

- `objective_delta.energy`
- `objective_delta.integrity`
- `objective_delta.fertility`
- `objective_delta.position_y`
- `objective_delta.information_store`
- `resolution_resource_delta.0`
- `resolution_resource_delta.1`
- `resolution_resource_delta.2`
- `resolution_resource_delta.3`

没有任何坐标在 9/9 source 中稳定为负。上述“正”只表示消融后 current-versus-selected-history 的绝对事实差异更大，即原对齐在这些坐标上选择了更接近当前事实的历史事件；它不定义更接近就是更好，也不能合成为 reward 或信用分数。

## 5. 轻量治理检查

- 数据与预期不符的根因：正式结果没有要求调整任务。主体—时间错位稳定改变 selector，但 objective-fact 为混合方向；这不是操纵失败，而是“机械相关”与“统一信用质量”必须分离。
- 新长期原则：没有新增科学原则；本轮把既有的 component-wise、禁止无依据标量化原则应用到 alignment ablation。
- 仅存在于聊天中的原则：没有。研究设计、结果边界和下一步约束均已写入协议、状态与本迭代文档。

## 6. 下一边界

Stage 3C-31 冻结为“alignment 对当前 selector 有机械作用，但 objective-fact 不形成统一方向”。下一次 runtime 干预必须共享 source checkpoint，设置精确 alignment ablation，匹配 compute/storage 成本，强制 rollback，并继续使用无 score 的逐坐标事实评估。不得从 selector agreement 或九个稳定正坐标直接进入 learned weight、reward、自动 keep/revert 或永久写入。
