# v0.163 思维链与语言认知设计治理

任务类型：`[DOC-GOV]`

本轮不修改 runtime。目标是将已达成的思维链、统一 ThoughtEvent、通信和语言研究边界从聊天讨论迁移到中文权威文档，并为下一轮 T1 实现建立清晰禁区。

## 决策

- 极短暂思维链与较长期记忆使用同一种 ThoughtEvent 表示和 identity；
- `node_state` 负责连续计算，ThoughtEvent 负责可重新寻址的事件；
- 不增加 `RETHINK`、`NO_ACTION` 或 confidence halt gate；
- read head、temperature、diversity suppression 和 retention policy 均不是 T1 内容；
- communication region 只承担 SignalEvent 接口，不拥有词义；
- 路标或强反馈筛出的行为码不能直接称为对象词；
- 跨 seed/区域比较以功能、指称分区、关系结构和反事实干预为准；
- 哈夫曼类比只作为成本约束编码同态假设。

## 下一边界

下一轮 `[EVOLVE-SUBJECT]` 只建立 T1 统一 ThoughtEvent 基础设施，并保持现有 Stage 3C bootstrap 可重现。
