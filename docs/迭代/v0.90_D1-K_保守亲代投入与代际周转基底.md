# v0.90 D1-K：保守亲代投入与代际周转基底

## 结果判断

D1-J 的 3 个独立 seed 和 120 tick 共享 checkpoint 配对足以确认机制接线、
守恒边界和较大的急性效应，但不足以评价演化。tick 480 时三组只产生
8、6、1 次出生，平均存活年龄接近整个运行时长，样本仍由初始主体主导。
增加同一路径内的 tick 或逐 tick 观测不能替代独立 seed 和多代替换。

## 本轮实现

- 增加同通道外部资源残余回流，回收储存衰减和死亡携带的原始资源；
- morphology gene 6 选择 0.6、1.0、1.4 或 1.8 的后代能量投入；
- 父体支付 0.2 事件开销和所选投入，并保留 0.45 能量储备；
- 投入完整转移给新生体，之后再支付既有发育成本；
- 较高投入降低可繁殖频率但提高后代初始质量，形成真实机会成本；
- 中和分支保持父体投入和全部成本，只移除后代获得的能量回报；
- checkpoint、clone、CPU/GPU action mask、执行结算和报告统一使用逐实体阈值。

四档平均父体总支出仍为 1.4，与旧固定成本相同；旧实现中未明确的
45% 新生能量和其余耗散被替换为显式、可遗传、可消融的物理语义。

## 证据边界

D1-K 首轮仍只运行 3 seed 的代际基底校准。只有源轨迹出现重复的后代替换，
才值得扩展为独立 seed 的演化面板。当前不设置适应、共存或生态位门槛。
