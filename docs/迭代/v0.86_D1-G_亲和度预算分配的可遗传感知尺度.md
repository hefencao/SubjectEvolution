# v0.86 D1-G：亲和度预算分配的可遗传感知尺度

## 结果输入

D1-F 三组共享 checkpoint 配对均满足运行合同。保留最强通道扩展半径的
分支相对 radius-one 分支，存活差为 +11、-20、-17，平均能量差为
-0.019667、+0.014523、+0.013636。相比 D1-E 的三组强负结果，能力边界
明显缩小，但仍没有重复的正向生态结果。

源群体的 resource-affinity specialization 只有约 0.15–0.17，实际资源使用
仍分布在多个通道。把全部额外半径压到唯一最强通道是过强的离散约束，
不应通过调低成本或增加奖励掩盖。

## 本轮实现

新增 `inherited-affinity-budgeted-gradient-radius-v3`：

- morphology gene 7 仍决定 1、2、4、8 的遗传总 reach capacity；
- 四个通道均保留 radius 1；
- `capacity - 1` 个整数额外半径单位按遗传 resource affinity 做 Hamilton
  分配；
- 余数相同时按最低通道索引确定性分配；
- 每个实体严格满足 `sum(channel_radius - 1) == capacity - 1`；
- D1-F 与 D1-G 对同一基因具有完全相同的总额外半径和维护、使用、发育
  成本；
- radius-one 中和仍保持基因、亲和度、成本、资源场和共享 checkpoint。

没有新增奖励、角色标签或结果反馈。

## 结果目录

`workflow.toml` 的结果输出改为 `result-path`。首次运行前使用：

```text
se-study config --set-result-dir /absolute/external/result-directory
```

设置写入被 Git 忽略的 `.se-workspace.toml`。相对输出文件名只会解析到该
项目外目录；项目内路径会被拒绝。完整项目压缩包不会包含该本地设置。
