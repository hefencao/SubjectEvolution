# v0.166 ThoughtEvent T3 最小前向 recall

## 任务身份

```text
[EVOLVE-SUBJECT] subject-vm: introduce minimal forward ThoughtEvent recall
```

## 实现

- 增加默认关闭的 `single-latest-prior-thought-event-recall-v1`；
- 每个主体只选择最近一个严格早于当前 tick 的 retained ThoughtEvent；
- selector 不使用 query network、随机数、temperature 或固定认知角色；
- `node_recall_port` 与 `node_recall_gate` 将 recalled coordinate 作为普通 node accumulator contribution；
- 当前 T3 fixed bootstrap 只在 readout-only node 9 上启用一个 ingress；
- commit 时将实际 selected event 写入统一 ThoughtEvent parent DAG；
- recall accounting 只记录搜索、读取、ingress 和 parent-link 数量成本；
- enabled recall 成为配置、checkpoint、clone 与 branch identity 成员；禁用配置保持旧身份。

## 正式实验

九 seed panel（12601～12609）比较 no-recall、identity、坐标置换和 zero-content 等成本 control。每 enabled arm/seed 形成 144 条前一 tick parent link；identity/rotate 的 coordinate 30 效应可在 float32 误差内精确重建，四臂 action/event 语义不变。

## 解释边界

T3 只证明最小前向 recall 机制可运行。identity parent-child cosine 仍接近 1，且当前 token 受 T2 已冻结的 rank-two fixed-bootstrap 边界约束，因此不能称为已形成思维链。下一项是 T4 延迟信息效用与 lineage echo 审计，不授权 multi-head 或 retention。
