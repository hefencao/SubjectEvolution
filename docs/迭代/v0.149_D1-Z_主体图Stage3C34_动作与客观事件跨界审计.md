## 问题

Stage 3C-33 在固定共同 horizon 下发现 exposure-only source-balanced
Objective-Fact 差异只出现在 seed 12305 和 12308。Stage 3C-34 不新增实验臂，
而是在所有八个冻结 branch 的相同事件集合上定位因果链停止位置：

```text
Subject-VM action potential
  → categorical sampled action
  → objective event
  → subject/source-balanced aggregate
```

## 输入与完整性

- 九个独立 source checkpoint：12301–12309；
- 两个共同 horizon 条件：3-tick exposure / 11-tick horizon 与
  6-tick exposure / 11-tick horizon；
- 每个条件四臂：aligned/ablated × guarded-live/read-only-control；
- 每个 source、mode、role 均为 144 个相同 event identity，tick 4–12；

- 得到的 21 坐标向量必须逐 source 精确重现 Stage 3C-33。

## 冻结结果

### 连续决策层

九个 source 全部出现 exposure×alignment 的 Subject-VM action-potential 差异，
每个 source 有 7–20 个非零事件。因此 Stage 3C-33 的零 source 不是“内部路径
完全没有变化”。

### 采样动作层

只有三个 source 出现实验 exposure 导致的实际 action change：

- 12305：3 个 alignment-specific crossing；
- 12308：1 个 alignment-specific crossing；
- 12307：1 个 alignment-common crossing，两种 alignment mode 都发生相同的
  `harvest → move_social` 转换，因此被 cross-mode difference-in-differences 消去。

其余六个 source 的连续差异没有跨过本次固定随机采样所实现的 action boundary。

### Objective-Fact 层

12305 和 12308 的四个 alignment-specific action crossing 继续产生 12 个
alignment-differential Objective-Fact 事件：

- 4 个与 action crossing 同事件；
- 8 个出现在后续 tick；
- 12305 的差异延续到 tick 12；
- 12308 从 tick 8 的单个 crossing 延续到 tick 12。

这两个 source 精确等于 Stage 3C-33 的两个非零 source。没有 source 出现
“event-level differential Objective-Fact crossing 存在，但只在后续 subject/source
聚合时抵消”的情况。

## 解释边界

本轮支持：

1. 更长 exposure 在所有 source 中都改变连续 Subject-VM 决策残差；
2. 稀疏 source effect 的直接分界是 alignment-specific sampled-action crossing；
3. 少量 crossing 可以通过世界状态继续传播成多个延迟 objective event。

本轮不支持：

- 某个 Objective-Fact 方向具有价值；
- 当前更新具有正确 causal credit；
- 自动 keep/revert、learned weight 或永久 retention；
- 通用 attention 或主体性结论。

冻结 trace 只保存 Subject-VM residual action potentials 和 selected-action
probability，没有保存完整 masked policy logits 与 categorical draw，因此无法计算
未 crossing 事件距离具体 action boundary 的数值 margin。
