# v0.138 D1-Z：主体图 Stage 3C-24 Rank-2 选择覆盖与 Score Margin 审计

## 目标

Stage 3C-23 已证明第二个主体/事件特异 visible coordinate 可以把 association-visible centered rank 从 1 提升到 2，但没有增加 commit、客观分化 source 或稳定客观坐标。本轮不继续增加维度，也不修改 addressing；只重建完整候选机会，区分：

- rank 2 是否改变 threshold 以上候选资格；
- 是否扩大实际选中的历史事件身份覆盖；
- 是否只是消除 score 并列并提高确定性；
- 是否增加少数历史事件的重复使用。

## 冻结实验合同

正式面板继续使用 seeds `12301..12309`，每 source 32 实体、16 bootstrap subjects、source tick 2、branch horizon 8、`rollback_after_ticks=3`、CPU、`edge_forward_gate` target、edge carrier enabled、normalized-dot similarity、threshold 0.8、latest/top-1、bounded delta、自动回滚和禁用永久保留。

两个 arm 仅复用 Stage 3C-23：

- rank-1：visible ports 29/30 都读取 uncertainty-mean；
- rank-2：port 29 读取 uncertainty-mean，port 30 读取筛选出的 objective port 7。

本轮新增内容全部位于 `src/se/analysis/`，不增加 runtime 或 checkpoint 字段。

## 分析方法

对每个 read-only control checkpoint，逐 stable subject 与 current event：

1. 排除 request 与 modulation control coordinates；
2. 按原 delay bounds 重建同主体历史候选；
3. 计算 normalized-dot score 与 threshold eligibility；
4. 按正式 latest/top-1 comparator 复算 winner；
5. 校验 stored event ID 与 similarity；
6. 统计 eligible identity、selected identity、复用次数、Gini、Shannon/inverse-Simpson effective count；
7. 统计 selected-threshold margin、best-second margin、eligible score spread 与 exact-best-tie frequency。

最高独立重复仍为 independent pre-bootstrap source checkpoint。事件、主体和窗口不能升级为 source replicate。

## 正式九 Source 结果

两个 arm 每 source 都有：

```text
unique eligible historical events = 112
above-threshold candidate references = 432
assigned current events = 112
```

因此 rank 2 没有改变候选资格，只改变 score 排序。

### Rank-1 duplicate coordinate

- selected identity coverage：0.7589–0.8393；
- maximum event reuse：3；
- inverse-Simpson effective fraction：0.6437–0.7467；
- exact best-score ties：所有 source 均存在，约占 assigned queries 的 0.446–0.643；
- best-second margin 的中位数为 0，多数 winner 仍依赖 latest tie-break。

### Rank-2 selected coordinate

- selected identity coverage：0.7143–0.7857；
- maximum event reuse：3–4；
- inverse-Simpson effective fraction：0.5773–0.6829；
- exact best-score ties：9/9 source 均为 0；
- best-second margin 全部为正，但最小值仍可低至约 `4.7e-9`–`4.0e-8`；
- selected threshold margin 仍为正，候选 opportunity 没有丢失。

Rank-2 selected set 在 9/9 source 都是 rank-1 selected set 的严格子集，没有新增任何 rank-1 未覆盖的历史事件身份。它在所有 source 中降低 unique identity coverage、提高 selection Gini、降低 inverse-Simpson effective coverage。

## 解释边界

本轮支持：

> Rank 2 消除了精确 winner 并列并改变了确定性排序，但没有扩大候选资格或 selected identity diversity；在当前 latest/top-1 工作点，它进一步集中复用了 rank-1 已覆盖的历史事件子集。

本轮不支持：

- 更大 margin 等于更正确 causal credit；
- 更高 rank 更好或更坏；
- 更多 identity coverage 具有固定价值；
- 复用集中度本身证明学习效果；
- 永久参数保留、自动 keep/revert 或 scalar reward；
- 当前 normalized-dot top-1 是通用注意力。

## 下一边界

保持 rank-2 readout、normalized-dot similarity、threshold、latest/top-1、target/carrier、delta、exposure 和 rollback 不变，进一步区分 winner 复用来自：

- 大量接近零但非零的 best-second margin；
- 重复或近重复 token geometry；
- 同一历史事件在多个 query 下占据局部邻域。

在该诊断完成前，不增加 top-k，不加入 novelty/coverage reward，也不引入 learned candidate weights。
