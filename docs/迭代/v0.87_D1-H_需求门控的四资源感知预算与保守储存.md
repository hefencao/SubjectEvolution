# v0.87 D1-H：需求门控的四资源感知预算与保守储存

## 结果输入

D1-G 三组共享 checkpoint 配对均满足固定额外半径预算、基因、资源场、成本
和随机性合同。保留亲和度预算分配的分支相对 radius-one 分支，存活差为
-3、-40、-15；平均能量差为 -0.089208、+0.090915、+0.007554。

D1-G 已证明多通道预算分配进入世界观察路径，但其 source 协议没有启用四通道
内部储存。预算只能按静态遗传亲和度分配，无法表达主体当前缺少哪种资源。
继续调整感知成本、半径档位或环境振幅会掩盖这一能力边界。

## 本轮实现

新增 `inherited-demand-gated-affinity-budgeted-gradient-radius-v4`：

- morphology gene 7 仍决定 1、2、4、8 的遗传总 reach capacity；
- 每个资源通道始终保留 radius 1；
- `capacity - 1` 个额外半径单位按“遗传亲和度 × 当前开放储存比例”分配；
- 储存比例以固定 4096 尺度量化，再用 Hamilton 方法确定性分配；
- 通道观察权重会重新归一到原遗传亲和度总预算，保持信号尺度不变；
- 半径分配和资源梯度聚合使用同一需求门控权重；
- 所有储存均满时确定性退回遗传亲和度；
- 维护、使用和发育成本仍只由遗传总 reach capacity 决定；
- radius-one 中和保持基因、亲和度、储存、成本、资源场和共享 checkpoint。

D1-H 的 source 协议复用现有 `resource-v5` 保守四资源储存与预采集容量约束，
并继续使用 D1-E 的持久多尺度环境。没有新增奖励、角色标签或结果反馈。

## 解释边界

本轮只建立“遗传容量—当前需求—世界观察”的可测表达链。三 seed、tick-480
source 和 120 tick 配对仍是轻量校准，没有通过阈值，不授权生态位、共存、
适应性或长期选择结论。
