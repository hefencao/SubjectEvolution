# v0.89 D1-J：固定总量的可遗传四资源储存分配

## 结果输入

D1-I 三组配对均满足共享 checkpoint、随机性、基因、当前储存、固定转化总量、
生理成本和资源场保持合同。存活差为 +1、-1、-2，平均能量差为
+0.011291、+0.089248、+0.112791。

遗传转化分配已经进入实际资源流，但相对均匀中和的有效维度变化只有
-0.034772、-0.040508、-0.044177，尚无重复人口方向。继续调高转化差异会
变成参数强化；当前更基础的限制是四个储存通道仍可独立扩张。

## 本轮实现

新增 physiology `transport-metabolism-messenger-tissue-resource-v9`：

- 保留 D1-I 固定总转化容量；
- 四个既有储存基因改为固定总内部储存体积的正权重；
- 每实体四通道储存容量之和严格等于配置总量；
- 任一通道增加必然占用其他通道体积；
- 当前已有储存不会在表型变化或干预时被截断；
- 新容量只约束后续摄入；
- 维护与发育成本按固定储存和转化总量计算；
- 资源作用、环境、采集、感知、动作和奖励保持不变。

新增 `neutralize-resource-store-allocation`：只把有效储存容量恢复为配置的中性
通道基准，同时保持基因、当前储存、转化分配、总储存体积、生理成本、资源场、
共享随机键和后代表达中和。

## 解释边界

本轮建立内部物质容量的守恒机会成本。三 seed、tick-480 source 和 120 tick
配对仍是轻量校准，没有通过阈值，不授权生态位、共存、适应性或长期选择结论。

## 轻量治理检查

- 数据与预期差异的根因不是运行链失败，而是 D1-I 遗传转化分配仍接近均匀，且四通道储存容量可以同时扩张；当前任务因此从转化分配调整为独立的储存总量约束。
- 本轮没有新增或修改长期奖励、角色、种群保护、通过阈值或审计原则。
- 新增长期约束“内部容量扩张必须有明确总量边界与机会成本”已写入架构、科学问题和本迭代文档，不仅存在于聊天中。
