# v0.127 D1-Z：主体图 Stage 3C-13 临时参数暴露充分性审计

## 1. 决策

v0.126 已证明 branch horizon 从 5 延长到 8 tick 会增加完成窗口，但不会在固定九 source 面板中新增离散 action crossing。该结果区分了“观察多久”和“单次参数实际作用多久”，但 `rollback_after_ticks=2` 下每次临时写入实际上只覆盖一个后续 semantic activation tick。

v0.127 因此选择一个实验变量：

```text
rollback_after_ticks: 2 -> 3
```

Stage 3C-5 既有合同要求 `control_horizon_ticks == rollback_after_ticks`，所以 control horizon 同步从 2 调整到 3。这是同一个 exposure-duration 变量的合同耦合，不是第二个独立机制变化。

保持不变：

- seeds `12301..12309`；
- 每 source 32 个初始实体；
- 16 个 fixed-bootstrap subjects；
- source tick 2；
- branch horizon 8；
- CPU backend；
- observation ticks 1；
- bounded delta、窗口预算、参数边界和 bootstrap topology；
- 主统计层级 `window -> stable subject -> independent source`；
- permanent retention disabled。

## 2. 分支级 exposure override

为了避免用两份配置重新生成 source 而把配置身份变化混入实验，paired plan 新增一个受限 branch-only override：

```text
subject_vm.live_write.rollback_after_ticks
subject_vm.evaluation.control_horizon_ticks
```

只允许这两个字段出现，且必须为相同整数。source checkpoint 仍由同一原始配置生成；两个 arm 每个 seed 的 source state hash、source config hash 和 bootstrap lineage 必须完全相同。live/control 两条分支在同一个 arm 内仍只允许 `subject_vm.live_write.enabled` 彼此不同。

该扩展没有新增 checkpoint schema、ledger、随机流、运行时持久状态或第二套生命周期。override 被写入 paired plan checksum 和 branch config identity。

## 3. 新增分析合同

新增：

```text
se.analysis.subject_vm_stage3c13_exposure_adequacy
se-subject-vm-stage3c13-exposure-adequacy
```

比较前必须验证：

1. 两个 arm 的 Stage 3C-7 工程筛查通过；
2. Stage 3C-8/10 checksum 与 study identity 一致；
3. 除 exposure duration 外所有 study 因素相同；
4. 九个 source 的 checkpoint state/config hash 与 bootstrap lineage 逐 seed 相同；
5. paired plan 仅包含两个被授权的 exposure 字段；
6. 两 arm 的 read-only control 在 thought token、action potential、sampled probability、action、resolution 和 objective delta 上逐事件完全相同；
7. divergence trace coverage 完整；
8. 窗口仍不能作为独立 replicate。

control reservation 的 ledger 时序允许因 horizon 同步而变化，但 read-only control 的实际行为和客观轨迹不得变化。

## 6. Exposure 2 与 Exposure 3 结果

```text
                                           exposure 2   exposure 3
completed paired windows                         143          141
live commits                                     144          144
mean effective semantic ticks/commit            1.000        1.993
action-potential difference events               371          423
sampled-probability difference events             377          426
discrete-action difference events                   3            2
sources with discrete-action divergence           2/9          1/9
sources with objective-event divergence           2/9          1/9
nonzero completed-window sources                  1/9          1/9
stable objective coordinates                     0/21         0/21
```

暴露时长增加后，每次 commit 的实际作用期由一个后续 semantic tick 基本扩展到两个；连续 action-potential 差异增加 52 次，sampled-probability 差异增加 49 次。但离散 action crossing 没有增加，反而由 3 次变为 2 次：seed 12304 原有的一次 crossing 不再出现，seed 12302 的两次 crossing 保持不变。

extended arm 少完成两个窗口，是因为更长 rollback horizon 使两个边界 pending transaction 在 export finalization 时被恢复，但对应 incomplete window 继续不进入证据；这不是 rollback failure，也没有改变 pairing coverage。

## 7. 解释边界

本轮支持：

- exposure duration 的 branch-only override 能在相同 source checkpoint 上被独立审计；
- 临时作用时间增加确实提高连续参数影响的可见覆盖；
- 连续 action potential / probability 差异不会单调转化为离散 action crossing；
- 在当前九 source 固定 bootstrap 面板中，单纯把 exposure 从一个后续激活 tick 延长到约两个，并不能解释稀疏离散分化；
- Stage 3C-8 仍没有跨 source 稳定方向。

本轮不支持：

- longer exposure 有害或有益；
- 更新机制有效或无效的最终判断；
- 2 tick 或 3 tick 是普遍最优 rollback duration；
- stable learning、正确 causal credit 或主体性；
- permanent retention、automatic keep/revert 或 scalar objective；
- fixed nearest-token、single-winner target 或当前 bootstrap graph 是通用注意力或自然演化结构。

离散计数的非单调变化来自阈值采样和路径差异，不应被解释为 utility 或负价值。

## 8. 下一边界

horizon 与 exposure 两个可见性变量都已完成单变量审计：更长 horizon 增加窗口但不增加 crossing；更长 exposure 增加连续影响但不增加 crossing。当前更明确的结构限制是全部 proposal/commit 仍集中在 `node_bias` 一个参数族，nearest-token candidate 仍集中于 delay 1 / similarity 1.0。

下一轮允许保持九 source、32 实体、8-tick horizon、`rollback_after_ticks=3`、bounded delta 和永久回滚不变，只做一个显式、可替换、无价值语义的 fixed-bootstrap parameter-family reachability 调整。不得同时改变 topology evolution、delta scale、实体数或永久保留。
