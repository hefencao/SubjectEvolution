# v0.130 D1-Z：主体图 Stage 3C-16 边资格载体可达性审计

## 1. 本轮问题

Stage 3C-15 已确认 `edge_forward_gate` 在 delay=1 edge 获得历史 state 后会影响 action potential，但 edge 0 没有 local eligibility carrier，无法进入 Stage 3C-1 exact-target binding。本轮只回答：

> 在 target family、token、图、source、delta、horizon、exposure、rollback 和聚合均不变时，只开放 edge 0 的现有 eligibility carrier，能否把该参数族接入完整 guarded-live paired chain？

本轮不比较参数族价值，不调整 step scale，不扩展 attention，不开启永久保留。

## 2. 单变量合同

两个 arm 固定：


唯一变化：

```text

```

使用已有 fixed-capacity eligibility 数组，不新增 runtime/checkpoint 字段，持久内存增长为 0。

## 3. 隔离验证

九个 source 全部满足：

- pre-bootstrap checkpoint state hash 相同；
- pre-bootstrap config hash 相同；
- stable subject selection 和 priming tick 相同；
- read-only control 的 thought token、action potential、sampled probability、action、resolution 和 objective facts 逐事件相同；
- read-only control 的 token、association、modulation proposal 计数与分布相同；
- 两份 bootstrap profile 除 edge 0 eligibility flag/gate 外相同。

因此 post-intervention guarded-live 漏斗差异不能归因于 source、RNG、target token、association 或 update-scale 漂移。

## 5. 允许的结论

允许：

- 当前 exact-target binding 对 edge family 需要合法 local eligibility carrier；
- `edge_forward_gate` 在 carrier 开启后可以进入 bounded update、temporary commit、rollback 和 paired evaluation；
- carrier-off 的零窗口是预期不可达基线，不是科学零效应 replicate；
- carrier-on 产生更多短程可见分化，但仍没有跨 source 稳定客观坐标。

不允许：

- 把 carrier 解释为正确因果信用；
- 把 edge-forward family 解释为有益或有害；
- 根据 3/9 source 分化授权永久保留；
- 把 eligibility magnitude 解释为 value；
- 引入 scalar reward、automatic keep/revert、topology evolution 或完整通用注意模型；
- 宣称 learning、subjecthood 或 emergence。

## 7. 下一边界

carrier-on arm 现在可以作为“机械可达工程基线”。下一轮若继续，不应再修改 carrier、family、delta、horizon 或 exposure，而应先选择一个单变量 allocator 问题，例如：

```text
fixed single-winner local carrier
vs.
bounded top-k / multi-candidate carrier allocation
```

该比较必须继续以 source checkpoint 为最高独立重复，并保留零结果、拒绝原因、自动回滚和 score-free 21-coordinate evidence。它不等于立即切换完整通用注意模型。
