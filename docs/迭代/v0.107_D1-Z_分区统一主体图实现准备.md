# v0.107 D1-Z：分区统一主体图实现准备

## 本轮性质

本轮只更新稳定文档、协议和版本元数据，不实现或启用新的运行时认知机制。

## 纠偏

D1-X/Y 将关系学习从即时固定 trust 改成延迟物质和知识账本，但仍由设计者规定了哪些事实属于利益以及如何写回关系。继续增加保护、冲突、机会成本等独立账本会形成越来越复杂的人工认知模型，因此不再作为主体形成主线。

项目允许预设通用认知架构，因为从完全无结构网络演化出跨时程有效计算可能需要不可接受的搜索时间，而认知架构本身不是研究目标。禁止的是预设具体认知内容和社会答案。

## 冻结方案

采用一张分区统一主体图：

- 快速感知—动作区；
- 持续状态区；
- 延迟关联区；
- 整合驱动—决策区。

所有区域共享节点、边和路由身份。区域只是早期塑形偏置，可在后续版本中改变容量、跨区带宽、节点归属和更新周期。区域名称不构成认知功能证据。

利益与决策可以高度重叠在同一 recurrent 图中。强制边界是行动、世界后果和延迟可塑性的时间顺序，不是预设 Actor-Critic。

## D1-X/Y 状态

状态：`rejected-as-primary-subject-model-retained-as-fixed-cognition-baseline`

保留用途：

- 延迟状态和 checkpoint 测试；
- 来源 provenance 测试；
- 多时程报告测试；
- 固定人工认知对照。

不再扩展更多命名利益通道作为主线。

## 下一实现阶段

只授权 Stage 1：

1. disabled-by-default 配置；
2. 固定容量节点、边、区域和状态存储；
3. checkpoint、clone、出生、死亡和区域分支生命周期；
4. disabled 路径零输出、零成本和结果中性；
5. CPU reference 和配置身份测试。

尚不实现：

- 图输出进入行动；
- 延迟可塑性；
- 人工 reward；
- 关系或 group 替换；
- Epoch 1 实验。
