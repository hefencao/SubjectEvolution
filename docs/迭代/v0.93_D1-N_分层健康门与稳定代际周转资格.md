# v0.93 D1-N：分层健康门与稳定代际周转资格

## 结论边界

D1-M 不能被简单判为成功或失败。两个 seed 在 tick 360 完整通过，第三个
seed 在 tick 240 因人口从早期过冲下降 30.43%，略高于 30% 目标而被提前
终止。当时其 alive 仍等于 128 个 founder 数量，并已有 56 个存活后代。
问题在于 v1 将“理想资格阈值”和“灾难性中止阈值”当成同一件事。

## source-health-contract-v2

v2 明确拆分：

- advisory：记录阶段是否按计划成熟，不终止可恢复运行；
- hard stop：只有越过宽松的灾难性下限才提前终止；
- required final：只有最终必需检查点决定是否授权下一阶段。

旧 v1 协议保持兼容和原语义，不会改写历史运行。v2 运行事件写入规范化合同
SHA-256；后续版本若修改阈值或协议，报告器会拒绝用新合同重新解释旧轨迹。

## D1-N 底座

本轮不增加基因。固定保守后代投入保持不变，并在正式 seed 前完成统一
物理通量校准：维护成本 0.010、采集倍率 1.30、再生率 0.027。所有实体
使用同一参数，没有基因优惠、奖励或种群保护。

内部校准使用的 seed 不进入科学证据。正式 workflow 使用 93101、93102、
93103，并要求 tick 480 时同时满足人口规模、出生周转、存活后代、平均世代、
founder 替换和末段稳定性。三个正式 seed 全部通过前，不允许添加能力、配对
或演化解释。
