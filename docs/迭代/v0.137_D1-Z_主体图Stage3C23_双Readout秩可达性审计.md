# v0.137 D1-Z：主体图 Stage 3C-23 双 Readout 秩可达性审计

## 目标

Stage 3C-22 证明 uncertainty readout 已产生主体/事件特异的一维 geometry，但 latest/top-1 仍集中复用同一可选历史集合。本轮保持 addressing、target/carrier、delta、exposure、rollback 与永久保留不变，只回答第二个现有 objective coordinate 能否把 association-visible centered rank 从 1 提升到 2。

## 数据筛选

分析层从冻结九 source 的 source checkpoint 只读重放八个 control tick，捕获全部 16 个既有 objective input port。候选必须在每个 source 中满足：与 uncertainty 和常数锚点组成的可见向量 centered rank≥2；每个 tick 存在主体间方差；每个主体存在时间方差；没有 query 丢失全部 similarity≥0.8 的历史候选。合格候选按“对 uncertainty 线性回归后的跨 source 最小残差方差最大”选择，端口号仅作为并列规则。

`local-resource-ratio-3`（port 7）被选中；其跨 source 最小残差方差为 0.02307362884349373，每 source 仍有 432 个 threshold 以上候选引用，零 query 失去全部可选历史。该选择没有价值语义。

## 单变量合同

两个 arm 都使用相同十节点 fixed bootstrap：node 8 把 uncertainty-mean port 11 写到 token port 29；node 9 无 action output、无 local eligibility，只写 token port 30。rank-one control 让 node 9 再次读取 port 11；rank-two alternative 只把 node 9 input 改为 port 7。

九 source、32 实体、16 bootstrap subjects、source tick 2、branch horizon 8、exposure 3、CPU、`edge_forward_gate`、edge carrier、normalized-dot、threshold 0.8、latest top-1、delta budget、自动 rollback 和 disabled permanent retention 均不变。

两臂的 pre-bootstrap state/config hash、stable subject 选择和 read-only objective behavior 全部一致；thought token 只允许 port 30 不同。pairing coverage 均为 1.0，rollback failure 与 objective clipping 均为 0，evaluation cost 均匹配。

## 结论边界

第二个主体/事件特异坐标在当前 fixed bootstrap 中机械可达，且能在所有 source 中形成 rank-two geometry。更高 rank 没有增加 commit、客观分化或稳定坐标，因此不能被解释为更好的 credit、更好的学习或更有价值的资源通道。

本轮不授权永久写入、自动 keep/revert、scalar reward、价值语义、主体性、learned attention 或通用注意力声明。

## 下一边界

固定 rank-two readout、normalized-dot、latest top-1、target/carrier、delta、exposure 与 rollback，审计 threshold margin、候选身份覆盖和复用集中度；在该诊断前不修改 addressing 或 retention。
