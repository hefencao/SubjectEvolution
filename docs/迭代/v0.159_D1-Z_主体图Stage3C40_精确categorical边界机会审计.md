# v0.159 D1-Z：Stage 3C-40 精确 categorical 边界机会审计

## 任务身份

```text
[MAIN-EXP] D1-Z: audit exact categorical action-boundary opportunity
```

## 设计

复用原 panel `12301–12309` 与独立 panel `12401–12409` 的 deterministic rank-two source state。每个 panel 运行相同的 `3 tick exposure / 11 tick horizon` 与 `6 / 11` 四臂干预，并开启已通过语义中立性门的 categorical trace。

主要量为：原 sampled action interval 到 uniform draw 的最小余量，以及 extended exposure 对该 interval 同方向边界的移动量。二者比值大于等于 1 时，原 action interval 不再包含 draw，发生实际 crossing。

## 冻结结果

- trace 精确重现 Stage 3C-34 的 crossing 数量和 source identity；
- 原 panel 的 alignment-specific crossing source 为 `12305、12308`，共四个事件；
- `12307` 在 aligned 与 ablated 中均 crossing，属于 alignment-common crossing；
- 独立 panel 没有 crossing，最大压力/余量比为 `0.6884819850`；
- 原 panel 最大比值为 `6.3326187051`；
- draw 很接近边界并不充分，CDF shift 较大也不充分；移动方向和 alignment mode 必须同时匹配。

## 解释边界

本轮解决精确 categorical boundary 的可观测性与事件级几何，但没有解释 source history 为什么形成不同的 logit/CDF pressure，也不授权 value、causal-credit quality、learned weight、keep/revert 或 retention。
