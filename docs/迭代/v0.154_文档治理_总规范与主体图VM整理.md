## 范围

本轮只调整文档权威关系，不修改 runtime、configuration、checkpoint schema、scientific workflow、source panel、冻结结果或 Stage 3C 解释。

## 已纠正的问题

1. `PROJECT_CHARTER.md` 混合了长期使命、当前实现状态、重复章节编号、追加式特殊规则和通用固定 seed 数要求；
2. `PROJECT_GOVERNANCE.md` 仍是逐版本检查的追加记录，不是跨版本长期规则；
3. `PARTITIONED_SUBJECT_GRAPH_VM.md` 把当前机制语义和 v0.114–v0.147 实验日记混在一起，并显示过时项目状态；
4. `AGENTS.md` 与 `ARCHITECTURE.md` 没有明确 Charter 和详细 VM 合同的权威位置。

## 整理后的权威关系

- Charter：使命、研究顺序、本体和项目级解释边界；
- Governance：长期推断、工作流、身份和文档规则；
- VM 文档：当前机制、所有权、阶段、安全和能力合同；
- Result ledger：冻结 Stage 3C 科学历史；
- Status 与 Issues：只保留当前队列和未解决问题。

原三份文档保存在 `docs/history/v0.153/`，明确标记为非规范审计快照。

## Charter 审查决定

项目使命和主因果顺序继续有效。以下过时或错位内容已处理：

- 从 Charter 移除当前阶段实现结论；

- 改为由冻结协议按独立 source history、支持结构和结论强度论证样本规模；
