# D3-C result interpretation

The supplied three-seed, 1500-tick D3-C run closes the identity-preserving external residue cycle in every seed. Store decay and death-carried raw stores deposit into the same four channels, residue releases back into those channels, and the external ledger remains valid.

The material cycle should therefore be retained. The next limitation is environmental rather than biochemical: final resource dimensions are only about 1.11–1.19 and mean absolute channel correlation is about 0.88–0.92.

In `orthogonal-four-resource-niche-v1`, channel-specific geometry controls initialization and seasonal growth modulation, but the logistic equilibrium is the same uniform channel capacity in every cell. Long-lived common depletion can therefore dominate the initial geometry and drive all channels toward the same spatial demand footprint.

This result does not justify a niche or trophic claim. It justifies replacing the disappearing initial pattern with an explicit, moving, channel-specific abiotic renewal target while preserving all D3-C material accounting.
