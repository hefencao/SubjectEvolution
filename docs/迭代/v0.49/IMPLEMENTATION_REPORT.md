# v0.49 implementation report

v0.49 responds to the completed D2-I result by expanding the reachable physical output space rather than alternating between module and environment endpoint audits.

Implemented:

- v3 compositional embodied module schema;
- locomotion-power, field-signal-power, and repair-drive routers;
- explicit structural and use costs;
- conserved material/energy repair semantics;
- output-only embodied neutralization;
- checkpoint, clone, intervention, progress, and cumulative accounting;
- combined harvest-plus-embodied output-basis diagnostics;
- paired `se-d2-embody` capability runner;
- v1/v2 default-path compatibility.

Not implemented:

- module copy-number evolution;
- dynamic module topology;
- arbitrary runtime output schemas;
- new sensors or named ecological roles;
- diversity protection;
- ecological niche claims.
