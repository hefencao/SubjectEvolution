# v0.161 Subject VM activation contribution trace

## 任务身份

- 类型：`[ENGINEERING]`
- Git 标题：`[ENGINEERING] subject-vm: export neutral activation contribution trace`
- 分支：`engineering/subject-vm-activation-contribution-trace`

## 目标

在不改变 Subject VM activation、policy sampling、checkpoint 或 branch identity 的前提下，导出同一次权威执行中的 node、edge、output-port 与 temporary-write contribution，使 Stage 3C-42 可以只读比较 `REST` output 的内部来源。

## 实现边界

- trace 默认关闭；
- activation 只执行一次；
- writer 位于独立 observation 层；
- trace 不进入 configuration、checkpoint、clone 或 branch identity；
- paired runner 支持显式开关与 subject ID 过滤；
- event ID 在 intent 建立后补齐，不回写 runtime state。

## 完整性门

fresh continuation 和真实 paired branches 均比较 trace 开/关：

- action 与 selected probability；
- categorical RNG trace 字节；
- checkpoint state hash；
- branch identity 文件；
- node/edge/output 数值重建；
- guarded-live/control temporary-write lineage。

全部通过后仅授权 Stage 3C-42 只读分析，不授权 causal attribution、value、keep/revert、learning 或 retention。

## 搁置的 action 讨论

`NO_ACTION` 不采用。低代价/低扰动 action 暂时搁置，未来必须使用独立行为与生态成本合同，不进入本轮工程设施或 Stage 3C-42 主线。
