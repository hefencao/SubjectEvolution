# v0.135 D1-Z：主体图 Stage 3C-21 主体/事件特异 Readout 审计

## 目标

在 Stage 3C-20 已证明可见 geometry 可达但仅为共享时间相位之后，检验一个现有 objective input 能否在不改变 action output 和更新合同的情况下产生主体及事件时间特异方差。

## 单变量合同

两个 arm 共用九节点 bootstrap。Node 8 为 readout-only linear node：无 output、无 eligibility、trace port 29、trace gate 1.0。唯一变量为 input port 0（constant-one）或 11（uncertainty-mean）。九 source、32 实体、16 bootstrap subjects、source tick 2、branch horizon 8、exposure 3、`edge_forward_gate` carrier-on、latest、top-1、delta、回滚和永久保留状态不变。

## 真实结果

- constant arm：1,008 个 delay-1 assignment，942 proposals，144 commits，129 windows，3/9 source 客观分化，0/21 stable coordinates。
- uncertainty arm：1,008 个 assignment，delay 1–6；846 proposals，144 commits，125 windows，2/9 source 客观分化，0/21 stable coordinates。
- uncertainty arm 在所有 retained tick 都有主体间方差；143/144 主体有时间变化；不同 source 的 subject/event matrix 不同。
- unique associated events 降至每 source 85–94，maximum reuse 升至 3。

## 结论边界

主体/事件特异 token geometry 已可达，但没有证据表明 historical evidence 更丰富、credit 更正确或学习已经形成。uncertainty 不具有固定价值语义；不授权永久保留、自动 keep/revert、scalar objective、主体性或通用注意力声明。
