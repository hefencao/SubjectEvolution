# D3-C external recycling plan

Schema: `d3-external-recycling-plan-v1`

Seeds: `[55001, 55002, 55003]`
Horizon: `1500` ticks

The four raw-resource identities are preserved through the external residue pool. Internal-store decay and death-carried raw stores deposit locally, remain external for at least one tick, diffuse with the existing channel diffusion rate, and return only to capacity available in the same resource channel.

No decomposer, scavenger, trophic level, ecological role, lineage protection, or diversity reward is introduced.
