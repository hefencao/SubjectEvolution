## 3. 正式九 source 结果

- baseline winner agreement：0.8229–0.9375。
- changed winner fraction：0.0625–0.1771，中位数 0.1354。
- same-state winner fraction absolute change：所有 source 均为 0。
- age-one winner fraction change：+0.0417 至 +0.1042，所有 source 同向。

### Positive-weight robustness

- 每 source 跨完整正因子面板的最低 baseline winner agreement：0.9479–0.9896。
- same-state winner fraction 最大绝对变化：0–0.0208。
- same-state winner 中 nearest-second-coordinate fraction：所有因子、所有 source 均为 1.0。

## 4. 冻结解释

当前 fixed bootstrap 中：

1. 第一可见坐标拥有离散 state-basin occupancy；
2. 第二可见坐标不是维持 state basin 的必要条件，但对 basin 内 winner identity 排序是必要的；
3. 任意非零贡献在宽面板内都保持同状态最近邻排序，因此 exact weight 1 不表现为细调唯一点；
4. weight 0 增加 age-one 选择，说明去掉主体锚定坐标会把排序推向更纯的时间/状态退化结构。

这些结果不构成价值、causal credit、learning、subjecthood、universal attention 或永久参数保留证据。

## 5. 轻量项目治理检查

### 数据与预期不符合及根因

预期候选包括“只有接近 weight 1 才稳定”和“任意正 weight 都稳定”。正式结果支持后者：rank collapse 改变 identity，但正权重宽面板保持局部排序。根因不是 threshold/candidate opportunity 改变，因为候选集合在重算前冻结；也不是 lineage 或导出错误，因为 checksum 与 stored-winner reconstruction 均为硬门。当前任务无需转向 runtime 机制扩展。

### 长期原则变化

没有新增或修改长期科学原则。既有原则继续有效：不预设奖励；机制干预必须有明确成本、消融和共享 checkpoint；诊断结果不能自动授权学习或保留。

没有。本轮 `src/gui/` 测试边界已写入 source fingerprint 注释、回归测试、项目状态和本迭代文档；Stage 3C-30 隔离与解释已写入协议、架构、VM、科学问题和 study workflow。
