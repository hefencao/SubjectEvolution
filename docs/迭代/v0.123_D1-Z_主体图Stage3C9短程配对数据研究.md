# v0.123 D1-Z：主体图 Stage 3C-9 短程配对数据研究

## 本轮目标

在不授权永久参数保留、不构造标量价值函数的前提下，让 Stage 3C-6/7/8 首次获得可复现的真实短程数据，并优先修复原型暴露的成对合同不对称。

## 已实现

- 新增 `se-subject-vm-short-paired-study` 与 `d1z_subject_vm_short_paired_v1` workflow。
- 新增版本化、哈希化的 8 节点/1 边固定 bootstrap graph；它被明确记录为 fixed-cognition engineering aid，而非演化结果或通用注意力模型。
- read-only control 使用零写入 control reservation，镜像 guarded-live 的 pending target、ledger、窗口目标数和 delta 预算。
- live-write ledger 升级到 v2，同时兼容 v1 checkpoint。
- paired plan 可显式执行 export-boundary transient finalization：停止语义 tick 后，通过现有精确 CAS 回滚 pending live write 并释放 control reservation。
- 未完成窗口不会进入配对证据；final checkpoint 不保留临时参数。

## 短程 pilot

默认参数：3 个独立 seed、source tick 2、branch horizon 5、16 个 bootstrap subjects、CPU。

结果：

- independent source pairs：3；
- completed paired windows：38；
- pooled pairing coverage：1.0；
- rollback failures：0；
- objective fact clipping：0；
- paired evaluation count-cost match：1.0；
- Stage 3C-7 engineering screen：通过；
- Stage 3C-8 component report：生成；
- 通过描述性 sign-and-interval stability screen 的坐标：0；
- 少量非零 energy/position/velocity 差异仅出现在 1/3 source，当前没有可重复方向。
