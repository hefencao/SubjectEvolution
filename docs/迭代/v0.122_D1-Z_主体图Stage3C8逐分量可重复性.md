# v0.122 D1-Z：主体图 Stage 3C-8 逐分量可重复性

## 本轮目标

在 v0.121 的 paired evidence 完整性筛查之外，建立逐客观坐标的重复性描述。该阶段只处理已经通过 Stage 3C-7 工程筛查的独立 shared-checkpoint pairs，不把窗口或主体伪装成独立 source replicate，不生成通用 objective scalar、自动 keep/revert 或永久参数保留授权。

## 已实现

- 新增 `src/se/analysis/subject_vm_component_reproducibility.py`：
  - 验证 Stage-3C-7 assessment checksum 和 adequacy screen；
  - 重新解析并验证其引用的 Stage-3C-6 export；
  - 以 source checkpoint state hash 识别最高层独立重复；
  - 对重复 source 输入去重，并拒绝同一 source 的冲突数据；
  - 先在稳定主体内平均 paired windows，再在 source 内平衡主体；
  - 保留 window-weighted mean 作为诊断，但不作为跨 source 主估计；
  - 对 21 维 objective fact sum、21 维 absolute-activity difference 和 3 个 count difference 逐坐标报告：
    - source replicate values；
    - 正、负、近零计数和比例；
    - mean、median、sample standard deviation、MAD、minimum、maximum；
    - 可配置 central quantile interval；
    - 仅作描述的 sign-and-interval stability screen；
  - 保留 source、subject、window 层级和每个 source 的主体汇总。
- 新增命令：

```bash
se-subject-vm-component-reproducibility \
  --assessment paired_evidence_assessment.json \
  --export-root path/to/paired_exports \
  --output component_reproducibility.json
```

- 默认描述参数：
  - 至少 3 个独立 source checkpoint；
  - near-zero tolerance 为 `1e-9`；
  - central interval 为 10%–90% quantile；
  - dominant nonzero sign fraction 至少 `2/3`。

这些参数只用于逐坐标工程描述，不是普适科学阈值或主观价值函数。

## 明确未实现

- objective coordinate weighting；
- universal scalar objective 或 overall benefit score；
- 把所有坐标压缩为单一通过/失败结论；
- 自动 keep/revert；
- 永久参数保留；
- 把符号一致解释为正向价值；
- 把区间排除零自动解释为因果效应；
- 窗口层或主体层伪重复；
- 新的 Subject VM runtime/checkpoint schema；
- 学习、适应、主体性或 Epoch 1 结论。

## 科学证据边界

v0.122 只能证明通过 Stage 3C-7 的独立 source pairs 可以按层级汇总，并逐坐标描述符号、离散程度与区间稳定性。即使某一坐标在所有 source 上同号且区间不跨零，也不能自动说明该坐标代表收益、更新具有真实因果性或参数应该永久保留。

下一步应先用小规模短程 pairs 生成真实 Stage 3C-8 数据。若窗口覆盖或 source 间离散度不合理，应修正分支/评估合同，而不是继续扩展永久学习链。
