## 当前启发式的解释边界

自主恢复模块在以下条件之一成立时接管已选行动：身体策略选择了 `MOVE_SOCIAL`、`SHARE` 或 `SIGNAL`，或者实体能量低于配置阈值且当前行动不是 `FLEE`。接管后仅在本地资源足够时 `HARVEST`，否则沿物理资源梯度 `MOVE_RESOURCE`；零梯度方向由稳定随机键生成。恢复组比例、低能量阈值和采集阈值均在配置中显式记录。

这个规则的价值是提供一个可审计、可重复、无社会信息输入的第一类恢复处理，从而验证实验管线和早期短期效应。它不覆盖独立防御、独立繁殖、学习恢复、模块维持成本或自主能力的自然退化；这些缺失是研究问题，不应通过扩大“自主”一词的解释来隐藏。
