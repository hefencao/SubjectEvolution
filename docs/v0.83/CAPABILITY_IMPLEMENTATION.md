# v0.83 capability implementation

This release follows `PROJECT_CHARTER` by pausing new audit expansion and adding
a costed inherited physical observation capacity. D1-D maps morphology
coordinate 7 to discrete resource-gradient radii 1, 2, 4, and 8. CPU and device
paths use the same normalized central-difference semantics; danger sensing and
the action vocabulary are unchanged.

The capacity has separate maintenance, active-use, and newborn-development
energy costs. `neutralize-resource-sensing-radius` fixes effective radius at one
without editing genotype or removing costs and is preserved by full checkpoints
and branch clones.

The initial D1-D run is a three-seed calibration from exact tick-480 checkpoints
with a 120-tick paired horizon. It has no threshold and does not authorize
adaptation, ecological-niche, coexistence, or selection conclusions.
