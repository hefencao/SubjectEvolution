# SE project status

Version: **0.76.0**

## Current result

D3-R confirms direct neutralization of the functional-module physiology-output path in all eight eligible seed panels, but the equal-seed median relative change in cumulative oxygen uptake is approximately -0.00011, below the preregistered 0.02 practical threshold. The candidate stops before replication.

## Mechanism-family funnel

A manipulation-confirmed bounded-path negative requires one aggregate family gate before any additional bounded candidate can be planned in the same family revision. This limits component fishing while preserving one direct test of whether the complete architecture has a material acute effect.

D3-S is the aggregate gate for `functional-modules` revision 1. It neutralizes the complete functional-module phenotype and measures cumulative total harvest over 120 ticks. A manipulation-confirmed terminal negative closes the family revision; a positive screen may advance only to disjoint-seed replication.

## Current exploration policy

