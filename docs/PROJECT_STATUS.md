## Architecture finding

The v1 module layer contained four independent copies of one functional form. Each module transformed the same ten inputs and published to the same four-channel harvest residual. Outputs were summed; modules could not signal to or condition one another.

Therefore v1 supported:

- parameter differentiation;
- different gates, transforms and channel weights;
- additive mixtures, dominance and cancellation.

It did not support:

- inherited module dependency;
- joint-only function;
- weak upstream modules carried through strong downstream effects;
- hierarchy among same-port modules;
- embodied functions outside harvest routing.

The negative D2-H result cannot be generalized to those unreachable mechanisms.

## v0.48 implementation

The opt-in v2 schema appends six lower-slot-to-higher-slot coupling genes to the four existing module blocks. Upstream signed signals multiplicatively modulate downstream contextual activation. The graph is fixed and acyclic, so evaluation remains vectorized and auditable.

Coupling genes are inherited, mutated, checkpointed and charged explicit maintenance/development cost. `neutralize-functional-module-coupling-output` removes only the mediated signal path while retaining genes, mutation, direct output and structure cost.

New diagnostics report hierarchy depth, coupling-weight effective dimensions, modulation, mediated signal, entity-level change, and per-level amplification/suppression. They do not feed the world.

## D2-I experiment scope

`se-d2-compose` creates paired fresh populations with composition active or output-neutral under the same v2 genome distribution, world seed, mutation streams and coupling cost. It reports descriptive paired differences and mechanism usage; it has no binary ecological or copy-number gate.

The immediate question is whether evolution uses the newly reachable combination space. If it does not, cost/mutation calibration is investigated. If it does but functional dimensionality stays low, the fixed harvest-only vocabulary—not the environment alone—is the next structural limitation.

## Compatibility

All previous v1 configs retain the archived additive evaluation path. New coupling genes are absent under v1, the new intervention defaults off, and ordinary simulation behavior remains authoritative-compatible when v2 is not configured.
