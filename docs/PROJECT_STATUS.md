# SE project status

Version: **0.73.0**

## Current result

The D3-O fixed-checkpoint resource-affinity screen yields a terminal negative promotion decision:

- eight of eight seed panels satisfy source and branch support;
- five seed effects are positive and three are negative;
- direction consistency is 0.625, below the preregistered 0.75 gate;
- the equal-seed median relative effect is about 0.00334, below the preregistered 0.01 practical threshold.

The candidate is stopped before replication. The compact v0.72 bundle does not contain a self-contained direct manipulation check, so the decision does not establish a universal causal null. It is specific to the failed promotion gates for total harvested resource over the fixed 120-tick acute horizon.

## Current exploration policy

```text
candidate specification
→ fixed checkpoint matched screen
→ durable promote/stop decision
→ disjoint-seed matched replication only after promotion
→ explicit acute confirmation only after replication
```

## Current gates

1. Fix the checkpoint tick before branch outcomes.
2. Hash-lock every source checkpoint.
3. Give each seed equal inferential weight.
4. Do not count windows, entities, or events as independent replicates.
5. Require a predeclared primary metric, direction and practical effect.
6. Require preregistered operational manipulation checks when a direct target metric exists.
7. Record every promotion or stop decision in the candidate ledger.
8. Do not silently reopen a terminal candidate by relabeling or changing thresholds.
9. Keep large long execution reserved for explicitly promoted confirmation.
10. Keep migration, specialization, coexistence and ecotype gates closed.
