## v0.37 D1-B

Implemented schema:

```text
affinity-sampled-exclusive-harvest-v1
```

Each HARVEST action samples exactly one channel from inherited affinity using
state-free keyed randomness.  Total request budget is unchanged and unused
budget is not reassigned.

In the 300-tick same-seed paired smoke, compared with uniform four-channel
requests:

- final resource dimensions: 1.4897 → 1.8248;
- resource mean absolute correlation: 0.7442 → 0.6083;
- demand temporal dimensions: 1.2015 → 2.0816;
- demand mean absolute correlation: 0.8758 → 0.5224;
- mean extraction efficiency: 0.9415 → 0.9093;
- final alive: 134 → 115.

The mechanism therefore produces demand differentiation with a measurable
opportunity cost.  It does not yet establish adaptive superiority or stable
ecology.

## Analysis contract

and input runtime versions.  If a resolved D1 config is present but progress
contains no `capacity_*` fields, analysis fails instead of silently producing an
incomplete D1 report.
