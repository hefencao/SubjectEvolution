# D1-B selective resource acquisition

## Schema

```text
affinity-sampled-exclusive-harvest-v1
```

The physical environment still exposes four fixed resource channels.  D1-B
does not add a role, species or hand-authored ecological type.  It changes only
the demand generated by an existing HARVEST action.

## Rule

For each harvester:

1. read its inherited fixed-budget four-channel resource affinity;
2. multiply by the configured channel extraction multipliers;
3. use a state-free keyed draw from `Stream.HARVEST_CHANNEL`;
4. select exactly one channel from that categorical distribution;
5. spend the historical total raw extraction budget on that channel;
6. request zero from the other channels.

The draw is keyed by run seed, tick and stable entity ID.  It does not use array
slot, local resource abundance, lineage, group label or population rarity.
CPU and GPU planners generate the same channel draw and request matrix.

## Budget and cost boundary

The total request per HARVEST action is unchanged:

```text
harvest_rate × sum(harvest_channel_multipliers)
```

Selective acquisition can be less efficient when the sampled channel is locally
scarce.  Unused request budget is not reassigned.  The mechanism therefore
creates an opportunity cost rather than a free specialization benefit.

The existing affinity ablation remains usable: neutralizing resource affinity
makes categorical probabilities neutral while preserving selective demand
semantics.

## Interpretation

This mechanism can produce divergent realized demand from inherited phenotype.
It does not by itself prove an ecological niche, specialization, adaptation or
stable coexistence.  Those require long-run phenotype–environment conditional
outcomes and shared-checkpoint affinity neutralization.
