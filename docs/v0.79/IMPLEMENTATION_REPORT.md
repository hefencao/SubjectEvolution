## D3-T scientific revision

v0.79 preregisters D3-T as a new `spatial-processing-support` mechanism family. This is not another control-policy or functional-module child. It isolates the existing conserved environment-to-processing interface in physiology resource-v7:

```text
phase-shifted local processing support
        × requested conservative raw-resource conversion
        ↓
realized converted resource flow
        + per-unit processing energy cost
```

Earlier D3-F/G panels tested movement response, orientation alignment and ecological interpretation. They did not estimate whether the support field itself has a practically material acute effect on realized conservative conversion. D3-T therefore uses a distinct directly measurable interface and does not reinterpret those earlier negative or insufficient results.

The aggregate intervention `neutralize-spatial-processing-support` replaces the local multiplier with 1.0 while preserving genotype, inherited storage/conversion capacities, current stores, resource fields, residue, checkpoint state and the configured per-unit processing cost. The primary metric is cumulative total converted raw resource over 120 ticks, with the unchanged 2% practical-effect threshold and seed as the independent unit.

## Direct target-engagement metric

An intervention flag is not sufficient because inventory-bearing entities could encounter only effectively neutral support. v0.79 adds the cumulative vector:

```text
sum(abs(local support - 1) * requested conservative conversion)
```

The paired candidate contract requires positive requested conversion in both branches, positive support deviation in baseline, and exactly zero support deviation in the neutral-support branch. This diagnostic is report-only and does not feed back into world state.

## Scope

No reward, sensor, action, resource amount, survival rule, reproduction rule, threshold, response horizon, seed rule or source checkpoint is changed. D3-T does not claim movement response, specialization, stable niches or long-horizon selection.
