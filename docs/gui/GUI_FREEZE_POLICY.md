# GUI 暂停开发策略

GUI 当前冻结在 v19。

## 允许修改

- 编译、链接、崩溃和内存安全缺陷；
- 错误显示会误导模拟结论的问题；
- 共享协议版本兼容；
- 新科学指标的最小显示或导出；
- profiling 证明的瓶颈；
- 测试和构建维护。

## 暂停修改

- 新视觉主题；
- 新面板和复杂布局；
- 更多快捷预设；
- 没有模拟语义支撑的新动画；
- CUDA/OpenGL interop；
- 仅凭截图主观调色的长期迭代。

## 恢复前置条件

恢复 GUI 路线前，至少完成：

1. 模拟 split tree 和测试基线；
2. step 不变量；
3. CPU/GPU 对照；
4. 一个可信演化实验；
5. 明确 GUI 的新需求来自模拟验证，而非纯视觉偏好。
