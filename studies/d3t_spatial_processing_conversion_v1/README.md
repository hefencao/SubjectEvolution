# D3-T spatial-processing conversion

This directory is the canonical index for the D3-T result chain.

- scientific design: [`DESIGN.md`](DESIGN.md)
- frozen screen and replication chain: [`RUN_CHAIN.md`](RUN_CHAIN.md)
- machine-readable study identity: [`study.json`](study.json)
- next-stage commands: [`commands/`](commands/)
- immutable evidence: [`frozen/`](frozen/)

Commands are intentionally kept out of this README. Each command file performs
one named step and is ordered by its numeric prefix.
