# D1-N staged healthy-turnover qualification

This study establishes a non-heritable demographic substrate before any new gene
is attached. It uses fixed conservative offspring transfer, a uniform calibrated
resource/maintenance budget, and `source-health-contract-v2`.

Intermediate deviations are retained as warnings. Only catastrophic floors stop
execution, and only the required tick-480 checkpoint authorizes the next stage.
Internal calibration seeds are not part of the formal evidence; the workflow
defaults to disjoint seeds 93101--93103.

Use `se-study show studies/d1n_staged_turnover_qualification_v1` before running.
