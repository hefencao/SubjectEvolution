# D1-Z Subject VM Stage 3C-33

This workflow tests whether the Stage-3C-32 runtime alignment intervention propagates through a longer temporary exposure into source-replicated Objective-Fact differences.

Three predeclared conditions are run from the same frozen nine-source rank-two checkpoint panel:

1. 3-tick exposure / 8-tick horizon (frozen Stage-3C-32 baseline);
2. 3-tick exposure / 11-tick horizon (horizon-only control);
3. 6-tick exposure / 11-tick horizon (exposure-only intervention).

Every condition retains the aligned versus cyclic-donor and guarded-live versus read-only-control four-arm structure. The study never adapts exposure after observing results, never scalarizes the 21 Objective-Fact coordinates, and never authorizes retention.

## Evaluation boundary

Live-ledger dose, fixed common-horizon trajectory support and rollback-window observation coverage are audited separately. Rollback-complete paired windows observe one subsequent tick and their completion support changes when exposure changes, so they are auxiliary diagnostics rather than the primary exposure estimator.

The primary estimator uses the identical 144 final-trace event identities per source, alignment mode and branch role over event ticks 4–12. Event-level live-minus-control facts are summed within stable subject and balanced across subjects and independent source checkpoints.

## Frozen result

The ledger confirms an exact 2× target-tick exposure increase with identical transaction and update identity in all 18 source×mode comparisons. The fixed-horizon trajectory exposure contrast is nonzero in seeds 12305 and 12308, and the extended condition adds seed 12305 to the nonzero source set. No signed or absolute Objective-Fact coordinate has a stable direction across all nine sources.

Stage 3C-33 is frozen as sparse, source-dependent trajectory propagation without a stable component-wise result. No value interpretation, adaptive extension, automatic keep/revert or retention is authorized.
