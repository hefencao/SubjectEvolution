# D1-P design: integrated plurality before targeted adjustment

## Correction of iteration strategy

The project must not add one gene, create one matching environment, and repeat a
full audit indefinitely. D1-O confirms that the healthy source can carry the
inherited offspring-investment interface. More importantly, the same config
already contains 704 inherited coordinates spanning morphology, action policy,
knowledge routing, memory, sparse selection, capacities, functional modules and
physiology. Its world already contains four asynchronous resource fields,
resource-specific body outcomes, oxygen, terrain, wear and mortality traces.

D1-P therefore treats this accumulated system as one integrated subject-
environment baseline. No new physical mechanism is added in this version.

## Panel

Three independent seeds run to tick 1200 with checkpoints at 240, 480, 720, 960
and 1200. Catastrophic floors stop a bottlenecked run. Final health conditions are
sample-eligibility conditions for a retention scan, not a renewed per-capability
qualification cycle.

## Persistence scan

The scan compares the first and final thin checkpoints within each seed and uses
cross-seed quorum. It reports retained, concentrated, thinned and lost inherited
coordinates, both for all living entities and living descendants. It does not
infer benefit, harm, selection or ecological function.

Adjustment is deferred until the panel shows a repeated problem. The next change
should target a shared physical bottleneck, cost mismatch, absent expression/use
path, or a genuinely lost block. The project must not automatically construct a
paired experiment for every coordinate.
