# Design

Stage 3C-19 preserves the reachable Stage-3C-16 `edge_forward_gate` carrier-on baseline, latest-on-tie, candidate limit one, nine independent sources, 32 entities, 16 bootstrap subjects, eight-tick horizon, exposure three, bounded delta, rollback and score-free evaluation. It reads the read-only-control trace only and changes no runtime state.

The analysis derives the coordinates visible to normalized-dot association after request and modulation controls are excluded. It reports per-coordinate variance, centered covariance rank and effective rank, uncentered direction rank, exact token duplication, all delay-eligible query/candidate scores, best-versus-second score spread and similarity-threshold margin. Tokens, subjects and pairs are nested observations; the independent source checkpoint remains the highest replicate unit.
