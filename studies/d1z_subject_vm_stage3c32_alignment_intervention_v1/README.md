# D1-Z Subject VM Stage 3C-32 four-arm runtime alignment intervention

This study converts the Stage-3C-31 read-only alignment result into a shared-checkpoint runtime intervention. For every frozen Stage-3C-23 rank-two source checkpoint it runs four branches: aligned/read-only-control, aligned/guarded-live, cyclic-donor/read-only-control and cyclic-donor/guarded-live.

Both alignment modes execute the same deterministic sort/copy path. The cyclic-donor arm changes only the association-visible port-30 subject binding while preserving the exact tick-wise float32 marginal, candidate opportunity, evaluation count, storage layout, horizon, random stream and rollback contract. Objective evidence remains 21 component-wise live-minus-control coordinates and is compared across modes as a source-balanced difference-in-differences.

The intervention can establish causal effects on selector identity and temporary update routing under this fixed bootstrap. It cannot define scalar value, credit quality, automatic keep/revert, learning, permanent retention, universal attention or subjecthood.

Run with `se-study run studies/d1z_subject_vm_stage3c32_alignment_intervention_v1`.
