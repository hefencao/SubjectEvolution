# D1-Z Subject VM Stage 3C-31 alignment ablation

This study reuses the frozen Stage-3C-23 rank-two read-only control chain and the checksum-bound Stage-3C-30 assessment. It isolates queries with at least two same-first-state candidates, then applies a deterministic tick-wise cyclic permutation of the second visible coordinate across subjects. The exact per-tick coordinate multiset, authoritative candidate opportunity and candidate-evaluation count are preserved while the coordinate is detached from each subject's own history.

The audit compares winner identity and the unchanged 21 component objective-fact contrasts of the selected historical events. It does not combine those coordinates into value, reward or an automatic keep/revert decision. It changes no runtime field, checkpoint schema, target, carrier, update, rollback or retention contract.

Run the declarative workflow with `se-study run studies/d1z_subject_vm_stage3c31_alignment_ablation_v1`.
