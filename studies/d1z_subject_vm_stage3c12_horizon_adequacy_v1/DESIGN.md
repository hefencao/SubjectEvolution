# Stage 3C-12 design

This study asks whether the five-tick branch horizon hides later divergence. It changes only the horizon from 5 to 8 ticks on the same nine seeds, 32 entities, 16 fixed-bootstrap subjects, source tick 2, CPU backend, update bounds and rollback/evaluation contracts.

Eight ticks is the maximum comparison horizon that remains fully visible under the existing bounded trace retention of eight ticks. The study does not enlarge the trace, add runtime logging, or preserve complete execution paths.

The assessment requires identical source checkpoint state hashes, identical bootstrap lineage, complete Stage-3C-10 trace coverage, and exact equality of all event-shaped trace arrays before the five-tick stopping boundary. The extra tail is then classified into new discrete-action crossings versus continued objective path divergence.

Completed windows remain nested observations. The independent replicate remains the source checkpoint. No scalar objective, value interpretation, automatic keep/revert, permanent retention, causal-credit conclusion, learning claim or subjecthood claim is authorized.
