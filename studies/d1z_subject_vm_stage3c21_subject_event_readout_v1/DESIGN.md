# Design boundary

Both arms share the same nine-node fixed bootstrap graph.  Node 8 is a
readout-only linear node with trace port 29, trace gate 1.0, no output port and
no local eligibility.  The only changed field is node 8 input port: 0 versus
11.  Port 11 is an already-approved observation uncertainty fact; its sign and
magnitude carry no fixed subjective value in this study.
