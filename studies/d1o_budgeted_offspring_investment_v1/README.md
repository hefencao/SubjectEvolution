# D1-O budgeted inherited offspring investment

D1-N qualified the shared physical turnover substrate on all three formal seeds.
D1-O therefore activates exactly one existing inherited interface: morphology
gene 6 selects a bounded conservative parent-to-newborn energy transfer.

The four levels average to the qualified fixed 0.9 endowment, so a random initial
population does not receive a population-wide mean debit increase. No new gene,
module, reward, role, resource rule, or environmental change is introduced.

The first required evidence is a new three-seed source-health panel on independent
seeds 94101--94103. Paired commands are intentionally absent until that attached-
capability source passes the unchanged v2 health gate.

Use:

```text
se-study show studies/d1o_budgeted_offspring_investment_v1
```
