# Design

Stage 3C-20 preserves the Stage-3C-16 reachable `edge_forward_gate` carrier-on baseline, latest-on-tie, candidate limit one, nine independent sources, 32 entities, 16 bootstrap subjects, eight-tick horizon, exposure three, bounded delta, automatic rollback and score-free evaluation.

The baseline leaves action-producing node 0 without a token trace. The alternative adds exactly one fixed-bootstrap readout: node 0's existing current scalar state is emitted through trace gate 1.0 to association-visible token port 29. Node execution, action output, parameters, target family, eligibility carrier, similarity, delay bounds and candidate allocator are unchanged.

The readout carries no reward, utility, polarity, trust or role semantics. It is a replaceable engineering shaping aid. Because the same bootstrap graph is installed in every selected subject, the assessment separately tests within-tick subject variance, between-tick variance and cross-source trajectory identity instead of equating score spread with event identity or learned attention.
