# D1-E persistent multiscale resource landscape

## Charter role

D1-D established that inherited resource-sensing radius reaches the physical
observation boundary and can be neutralized while preserving genotype and all
registered costs. Its source environment used the archived v1 orthogonal schema,
whose channel geometry is not maintained by moving-target renewal. D1-E repairs
that substrate mismatch before making any ecological claim.

## Environment contract

The `persistent-multiscale-four-resource-renewal-v3` schema keeps four existing
resource channels and the existing conservative world kernel. Each channel has a
distinct toroidal primary spatial frequency, an independent secondary mode,
cycle period, phase, and diffusion rate. The moving renewal target continuously
maintains these scale differences. No entity, lineage, group, or measured result
feeds back into resource generation.

The configured primary wavelengths span coarse to fine structure on the same
32x32 grid. This creates an actual information-scale tradeoff for inherited
radii 1, 2, 4, and 8 without rewarding any radius or naming ecological roles.

## Calibration boundary

The first run repeats the D1-D cost-preserving radius-one neutralization from
three exact tick-480 checkpoints for 120 ticks. It checks whether the persistent
multiscale substrate produces measurable, non-degenerate consequences. There is
no threshold, adaptation claim, coexistence claim, or selection claim.
