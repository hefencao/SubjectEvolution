# D1-Z Subject VM short paired infrastructure study

This workflow generates a deliberately small, short and CPU-only Stage-3C paired dataset from three independent shared checkpoints. It uses one explicit fixed bootstrap graph to make the already implemented token, eligibility, association and rollback pipeline reachable without waiting for topology evolution.

The bootstrap graph is classified as a fixed-cognition engineering aid. It is not an evolved topology, a universal attention model, an Epoch 1 candidate or evidence of subjecthood. Every live parameter change is restored before export. Pending end-of-run transients are finalized with the existing CAS rollback path without executing additional semantic ticks, and incomplete windows are excluded from evidence.

The workflow is intended to answer only whether the current paired evidence pipeline can produce complete, matched, score-free infrastructure data. It does not decide whether any objective coordinate is desirable or whether an update should be retained.
