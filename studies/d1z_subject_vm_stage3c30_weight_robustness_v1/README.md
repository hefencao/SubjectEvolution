# D1-Z Subject VM Stage 3C-30 weight robustness

This study reuses the frozen Stage-3C-23 rank-two read-only control chain and the checksum-bound Stage-3C-29 assessment. It keeps the authoritative raw-threshold candidate set fixed, excludes source-boundary single-candidate assignments, sets the second visible coordinate weight to `0` as the rank-collapse ablation, and scans the predeclared positive panel `0.1, 0.25, 0.5, 1, 2, 4, 10`.

The audit asks whether the recurrent basin is tied to one exact coordinate magnitude or whether the first coordinate owns state occupancy while any non-zero second-coordinate contribution robustly resolves within-state winner identity. It changes no runtime field, checkpoint schema, candidate opportunity, target, carrier, update, rollback or retention contract.
