# Design

Stage 3C-15 established that `edge_forward_gate` is mechanically visible after the delayed edge has prior state but is unavailable to the current exact-target binding selector. Stage 3C-16 changes only that reachability fact.

Both arms route the fixed one-hot modulation coordinate to token port 27 (`edge_forward_gate`). In the baseline, edge 0 retains zero eligibility gate and no local-eligibility flag. In the alternative, edge 0 receives the existing bounded local-eligibility flag and gate 1.0. The edge topology, forward value, delay, bandwidth, action path, source state, addressing, fact projection, update scale, rollback and score-free evaluation remain fixed.

The zero-window baseline is expected evidence that proposal generation alone cannot bind an edge family without a valid local carrier. It must not be pooled with completed windows or interpreted as a failed biological source. The alternative may establish engineering reachability and short-term paired visibility, but it cannot establish credit quality, value, learning, subjecthood or permission for permanent retention.
