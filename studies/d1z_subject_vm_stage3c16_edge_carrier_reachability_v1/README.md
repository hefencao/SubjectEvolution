# D1-Z Subject VM Stage 3C-16

This workflow compares two frozen nine-source `edge_forward_gate` arms. Both use the same target token, graph, source panel, bounded delta, exposure and branch horizon. The only bootstrap difference is whether edge 0 owns one local eligibility carrier.

The carrier-off arm is an intentionally unreachable funnel baseline and is not treated as a Stage-3C-8 replicate. The carrier-on arm must pass the existing paired-evidence contracts before its objective coordinates are summarized. Checkpoints and ordinary run directories are excluded from the packaged research artifact.
