# Design boundary

## Single changed factor

Stage 3C-11 changes only the number of independent source checkpoints from three to nine. The entity count (`32`), source tick (`2`), branch horizon (`5`), fixed-bootstrap subject count (`16`), CPU backend, update bounds, rollback duration, evaluation contract and disabled permanent retention remain unchanged.

The predeclared source order is `12301` through `12309`. The first three sources reproduce the v0.124 pilot prefix; the remaining six are retained regardless of zero or nonzero outcomes.

## Replicate hierarchy

The highest replicate is an independent source checkpoint. Entities, stable subjects and paired windows are nested observations. More windows can improve one source estimate but cannot increase the independent source count.

Stage 3C-11 reports prefix sensitivity from three through nine sources, source-level incidence of discrete-action and objective-event divergence, completed-window nonzero source incidence and descriptive Wilson intervals. These are uncertainty diagnostics, not significance tests or value scores.

## Diagnostic contract correction

Stage 3C-10 now separates the paired admission contract from later shadow-transaction path equality. Control reservations must mirror admitted target/window capacity and paired evaluation counted cost. Once the live branch changes its own future internal path, later transaction preparation counts need not remain equal and are not by themselves a paired-contract failure.

Stage 3C-10 also reports retained tick coverage. If a future horizon exceeds the trace ring's observable prefix, divergence counts are explicitly lower bounds rather than false zeros.

## Forbidden conclusions

The expanded panel does not authorize permanent retention, scalar reward, automatic keep/revert, causal credit correctness, attention optimality, stable learning, subjecthood or Epoch 1.
