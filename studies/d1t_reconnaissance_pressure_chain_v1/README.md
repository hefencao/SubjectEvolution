# D1-T：对抗、负重与侦察信息价值链

D1-S 已经在三个正式 seed 中产生物理异质、真实群内原料交换和多个持续加工分工群体，但其中一个 seed 经历深人口瓶颈，因此总体环境资格仍未通过。

D1-T 不预设“斥候”职业，也不增加奖励或专属基因。它先补齐此前缺失的物理价值链：携带原料造成移动负担；不同联盟在同格或相邻局部范围争夺重叠原料时承担对称损耗；已有遗传感知距离可用于危险；局部争夺进入现有危险信号；来源明确的危险消息为 FLEE 提供远离发送者的方向；接收者结果仍只作观测记录。

本 study 只包含单 seed 机制调试。即使完整链路出现，也不证明斥候角色、信息因果收益、选择或适应，更不授权基因审计。

冻结后的 debug seed 101011 已接通完整链路并保持人口/谱系底座，但没有持续候选谱系；因此当前仍不声明斥候角色，也不启动正式 panel。
