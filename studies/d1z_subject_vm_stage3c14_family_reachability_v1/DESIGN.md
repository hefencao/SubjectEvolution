# Stage 3C-14 design boundary

## Single changed factor

The baseline fixed bootstrap writes its one-hot modulation target coordinate to token port 23 (`node_bias`). The alternative writes the same activation to token port 25 (`node_output_gate`). Both target coordinates are excluded from association similarity. Both families bind the same locally eligible node, use the same proposal signal, bounded step, exposure duration, branch horizon and automatic rollback.

## Isolation

Each arm is generated from the same pre-bootstrap source state for every seed. The assessment requires equal pre-bootstrap state/config hashes, equal selected stable subjects, profiles differing only in target-family routing, equal read-only objective/action behavior apart from the authorized token-coordinate relocation, and equal upstream control funnel/association diagnostics.

## Rejected pilot

`node_bias -> node_input_gate` is not used as the scientific comparison because node 0 reads the `constant-one` input port. In that bootstrap, a bias delta and an input-gate delta are algebraically equivalent.

## Interpretation boundary

The study tests whether a different generic parameter role changes short-term visibility. It does not rank families by value, validate credit assignment, authorize retention, establish learning, or claim a universal attention architecture.
